# CatalogMatrix closure-profile fixtures

Synthetic, no-network fixtures for the proposed `STAC_DCAT_PROV_CLOSURE_V1` profile.

- `valid/` contains aligned `READY` and `HOLD` records.
- `invalid/` contains schema-negative records.
- `semantic_invalid/` contains schema-valid alignment or decision failures.
- `expected_findings_manifest.json` defines exact outcome and reason-code polarity.

The fixtures do not narrow the broad CatalogMatrix contract and are not real catalogs, proof packs, policy decisions, releases, or factual Kansas claims.
