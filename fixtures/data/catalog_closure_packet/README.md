# `CatalogClosurePacket` synthetic fixtures

The fixture family is synthetic and no-network. It contains no live source, catalog, evidence, policy, release, or public endpoint.

Valid fixtures exercise `PASS`, `HOLD`, and `DENY` readiness outcomes. Invalid fixtures bind exact failure codes for deterministic hash mismatch, catalog-family coverage, ordering, identity/digest agreement, record resolution, policy consistency, review consistency, release/rollback readiness, canonical references, and authority overclaim.

A successful replay proves only the bounded contract and validator behavior.
