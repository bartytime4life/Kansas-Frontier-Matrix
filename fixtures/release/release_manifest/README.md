# ReleaseManifest fixture profile

`cases.json` contains a closed synthetic, no-network matrix for the dual-profile ReleaseManifest schema.

- four valid cases preserve the legacy branch and exercise internal, public-intended, and correction candidates;
- two schema-negative cases fail closed;
- fifteen schema-valid semantic-negative cases pin exact finite outcomes and finding-code sets.

The validator evaluates each embedded candidate independently and emits deterministic, value-free diagnostics. No fixture represents a real source, policy decision, reviewer, artifact, signature, release, public URL, or published KFM product. Identifiers and digests are synthetic.
