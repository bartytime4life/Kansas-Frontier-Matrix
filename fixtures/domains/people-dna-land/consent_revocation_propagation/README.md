# Consent revocation propagation fixtures

Synthetic, no-network cases for the proposed `ConsentRevocationPropagationAssessment` profile.

The manifest covers active in-scope consent, scope mismatch, revoked, expired, unknown, and evaluation-error states. Negative cases prove exact seven-surface coverage, action/receipt coherence, revocation propagation, status timing, deterministic profile hashing, and the no-authority boundary.

The fixtures contain no real names, people, relationships, DNA, kit identifiers, consent credentials, locations, source records, or released artifacts. Receipt references are inert synthetic declarations and are not resolved or authenticated by the validator.
