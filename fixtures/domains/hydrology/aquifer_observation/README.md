# AquiferObservation fixtures

Synthetic, public-safe fixtures for the proposed closed
`AquiferObservation` schema. Valid cases exercise numeric and explicit no-data
measurements, both with and without an aquifer-context link. Invalid cases
exercise source-role collapse, embedded Geology authority, missing measurement
basis, and numeric-value/no-data collapse.

These fixtures are not source records, evidence closure, policy decisions,
proofs, release records, or publication authority.
