# ClaimEnvelope fixtures

Synthetic, no-network fixtures for the proposed `ClaimEnvelope` contract.

- `valid/` proves draft and published-generalized examples accepted by the closed schema and local semantic rules.
- `invalid/` contains schema-negative cases.
- `semantic_invalid/` contains schema-valid cases that must fail local semantic checks.
- `expected_findings_manifest.json` is the exact polarity and reason-code authority for fixture replay.

These fixtures do not assert real Kansas facts, resolve evidence, approve policy, release data, or authorize publication.
