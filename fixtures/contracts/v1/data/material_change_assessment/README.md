# MaterialChangeAssessment fixtures

Synthetic, no-network fixtures for the proposed shared material-change assessment profile.

- `valid/` proves `NON_EVENT`, `PROMOTION_CANDIDATE`, and `HOLD` shapes.
- `invalid/` proves digest/flag coherence, material/outcome pairing, required criteria, time ordering, and the no-authority boundary.

Fixtures use invented identifiers and digests. They contain no source bytes, real observations, sensitive locations, rights assertions, policy approval, release state, or publication authority.
