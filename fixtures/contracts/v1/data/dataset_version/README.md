# DatasetVersion fixtures

Synthetic, no-network fixtures for the proposed `DatasetVersion` v1 shape.

- `valid/` contains retrieval, processed-derivative, and public-safe published examples.
- `invalid/` contains one schema-negative case and reviewed semantic-negative cases.
- `invalid/expected_findings_manifest.json` binds every invalid fixture to exact reason codes.

These records are test inputs only. They do not describe live Kansas data, activate a source, resolve rights or sensitivity, prove evidence, authorize release, or create public-use authority.
