# Synthetic GeoParquet 2.0 RC PyArrow carriers

This directory is reserved for the exact output of
`tools/experiments/geoparquet/generate_pyarrow_25_carriers.py`.

The committed carriers, once generated and reviewed, are wholly synthetic and
must remain byte-identical to a rerun under the pinned PyArrow 25.0.0 wheel.
They are test evidence only, not source data, release candidates, public
datasets, or proof of cross-engine interoperability.
