# Conditions source-role readiness matrix fixtures

This directory contains one synthetic, inactive readiness matrix and isolated
mutations. The matrix binds existing classification, observation, and forecast
fixture profiles while holding model, survey, and aggregate interoperability.

The fixtures contain repository-relative paths and synthetic role labels only.
They contain no source payload, observation value, geometry, credential,
EvidenceBundle, policy decision, review approval, release, or public artifact.

`PASS` proves local matrix coherence only. It does not adopt a common source-role
profile or authorize lifecycle, release, publication, or public use.
