# ThresholdPolicyRegistry fixtures

Synthetic, no-network fixtures for the inactive unresolved-slot registry.

The valid fixture contains no operator, value, unit, effective date, consumer
binding, or authority. Invalid fixtures prove that a numeric value and an active
binding are rejected by the closed schema. Focused validator tests cover
identity, ordering, reason posture, pressure-reference safety, parser limits,
and governance overclaims.

These fixtures do not establish an accepted threshold, scientific conclusion,
policy decision, watcher trigger, source activation, promotion, release,
publication, notification, or public-use authority.
