# RepresentationReceipt fixtures

Synthetic, no-network fixtures for the proposed shared representation-receipt profile.

- `valid/` covers exact tiles, generalized vectors, and synthetic/3D carriers.
- `invalid/` covers placeholder digests, missing evidence, missing reality-boundary
  notes, self-supersession, and false authority claims.

No fixture contains real source bytes, sensitive geometry, protected locations, rights
assertions, policy approval, review approval, release state, or publication authority.
