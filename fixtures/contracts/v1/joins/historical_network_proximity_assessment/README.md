# Historical network proximity assessment fixtures

Synthetic, no-network cases for the proposed `HistoricalNetworkProximityAssessmentCandidate` profile.

The manifest covers exact and approximate historical candidates, non-overlapping intervals, ambiguous and unresolved assertions, modern-context abstentions, and fail-closed time, distance, uncertainty, interpretation, hash, schema, and authority failures.

No fixture contains a real place, route, name, coordinate, geometry, address, parcel, person, infrastructure location, source record, or released artifact. Every reference is an inert synthetic identifier; the helper does not resolve or authenticate it.
