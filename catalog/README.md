## Purpose

Preserve a visible, fail-closed redirect for historical root-level catalog-family
paths while their governed responsibilities remain elsewhere. Keep legacy links
usable, identify canonical destinations, prevent parallel writers, and preserve
correction and rollback context. The long-term goal remains verified retirement,
not growth of this deprecated tree.

The parent [project README](../README.md) explains KFM. This page owns only the
local containment contract; it does not migrate, delete, regenerate, release, or
publish any descendant.
