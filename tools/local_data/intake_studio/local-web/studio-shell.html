YOU CONTROL THE ACCOUNTS

Users & access.

Local Studio accounts—not operating-system users. No public signup, shared default password or outside identity provider.

Administrator

Manage accounts, review evidence, and use existing private preparation tools. No automatic restore or publication.

Operator

Add intake files, import evidence, and record acceptance or recovery observations. Cannot manage users or approve reviews.

Viewer

Read private workspace data and exports. Cannot upload, edit, review, or administer users.

Local accounts

Create, reset or change access

New and reset accounts must change their temporary password before opening private data. Disabling, resetting or changing roles revokes existing sessions. The last active administrator is protected.

Recent account activity

Latest 500 events. Passwords, setup codes and session tokens are not included.
