# County environmental cadence calendar

This inactive Explorer feature adapts Pass 32 card `KFM-P32-FEAT-0015` and the repository's `CountyEnvironmentalRecencySpineCandidate` into a strict, table-first weekly calendar.

An available projection shows exactly six synthetic lanes—air, biodiversity, hydrology, imagery, soils, and vegetation—with check, source-health, and reason states. `COMPLETE` or `HOLD` describes fixture coherence only; it is not an environmental interpretation or a source-health assertion.

The adapter requires an exact pre-governed projection fixed to fixture-only, inactive, no-interpretation, no-publication, and no-public-use posture. Missing or malformed input renders nothing; finite abstain, deny, and error projections expose no county, source, time, or lane detail.

This module is not mounted on a route. It performs no transport, source probing, source-health authoring, policy evaluation, lifecycle write, promotion, release, deployment, publication, or public-use action.

Validation lives in `apps/explorer-web/tests/county-environmental-cadence-calendar.test.ts` and the isolated browser fixture. Rollback is a focused revert of this additive feature packet.
