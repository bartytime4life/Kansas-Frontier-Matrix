# Prepared collection review

The existing Local Atlas now opens on **Prepared review**. Choose one of six pinned collections and select its complete prepared folder from the protected WORK store. Every declared member and the exact manifest must match before maps, tables or review notes are made available. The optional operator copy marker is ignored and cannot extend the selection. A changed, incomplete, duplicate, unsafe or oversized selection stays held.

Monthly normals offer 24 station views and two complete flag-bearing tables. Frozen USGS discharge offers two stations and 193 observations; values are provisional and stale. Census offers 105 generalized statistical counties. Climate history shows the retained four-station archive's station/year/element coverage and missing/quality/trace counts; it does not load the full archive automatically. IEM offers all 9,760 captured wind rows and station coverage. NADCON5 offers exact offline dependency references and limitations; it never downloads, installs or executes a grid transform.

Map previews use the existing local-only Atlas carrier, with explicit false admission/evidence/release flags. Field values, units, dates, source attribution and limitations remain visible; numerical coloring uses the selected captured frame only. Feature clicks remain private Atlas inspection, not Evidence Drawer or AI input. Prepared fits mark the derived camera private/redacted. Tables preserve source strings and missing markers and render 40 rows/page. No interpolation, current telemetry, survey accuracy or continuous historical coverage is asserted.

Files stay in browser memory. There are no new server, R2, D1 or companion API routes; no direct browser access to protected RAW/WORK stores; no automatic path or reference fetch; no payload bundled into Site/GitHub source. The same owner-private hosted Site can review folders selected on the owner's device. Other devices require those exact prepared files locally; the Site cannot retrieve this PC's protected store. Closing Local Atlas, changing collection or suspension discards pending work and removes overlays. No bytes enter released catalogs, saved contexts, reports, exports, evidence or AI context.

The owner confirmed public-use availability in the conversation. That is recorded separately from source-specific terms, exact acquisition dates, units/version compatibility, routing, independent sensitivity/accuracy review and release. KDOT permissions/capture locators, PRISM dates/exact monthly units, NWM v3.1/v3.0 geometry/gauge compatibility and new Earth Engine exports remain held; the UI supplies no approval controls.

Placement: app/ owns the existing Atlas adapter/control/style implementation and its immutable device-review pins; tests/ owns behavioral checks; docs/ owns this explanation. Accepted ADR0029 and Directory Rules sections10/11/15 preserve external WORK and receipt authority. The pins are UI-owned capability selections, not a parallel source registry, rights policy or release home.

Rollback: remove the additive prepared-review source change or deploy the preceding saved Site version; clear browser review first. Existing provider refresh behavior, Site identity/audience, DB/R2 bindings, local state, active acquisition jobs and all protected original files remain intact. Data promotion and independent acceptance stay separate from code deployment.

Mobile controls: Collapsing resets the sheet scroll and hides section navigation until controls expand, so the collection heading and actions remain in view. View map keeps the prepared control mounted and shows its own collection/frame, units, range, visibility, selection, verification cancellation and map actions in the compact bar. Fit review collapses the sheet before measuring actual map/sheet rectangles, marks the derived camera private, and ignores queued fits after clearing, changing member, suspension or unmount. Inspect features/details expands controls and focuses the prepared feature selector. Verified file buffers remain in the child; parent state receives only presentation fields and action callbacks. No preparation is persisted. These controls do not supply independent source acceptance or change the admission/release flags.
