# Lightning layers and observed flash loop

The NASA LIS/OTD layer is a fixed 1995–2014, approximately 0.5° flash-rate climatology. Its WMTS date is a tile carrier, not an event date. It must not be replayed as individual lightning strikes. The NOAA nowCOAST layer is a separate 15-minute, 8 × 8 km strike-density raster. Neither layer supplies individual flash coordinates.

The **Observed satellite flash loop** is a third, opt-in layer. The Site requests recent NOAA GOES-19 GLM flash-centroid GeoJSON through the independent, public [Atmostorm API](https://atmostorm.com/api-docs/endpoints). GLM is a total-lightning optical sensor: it includes in-cloud flashes, and each centroid is a cloud-top estimate rather than a ground-contact strike. The displayed marker radius and violet halo encode playback time and selected persistence, not measured physical flash extent, intensity, or location uncertainty. Energy and area values remain in the response for future inspected details; marker size does not currently encode them. [NOAA product metadata](https://www.ncei.noaa.gov/access/metadata/landing-page/bin/iso?id=gov.noaa.ncdc%3AC01527) describes the flash time and energy-weighted centroid.

The loop offers 5, 15, 30 and 60 minute request windows; speed, pulse persistence, opacity, scrubbing, step and repeat controls are independent of the climatology and density opacity controls. All playback uses returned flash times and coordinates; it does not interpolate missing events. Reduced-motion mode suppresses autoplay and animated halos. The upstream `state=KS` shortcut is treated as a Kansas-area query, not a verified state-boundary intersection; near-edge points are disclosed. A quiet or unavailable feed is not an all-clear.

The Site route fixes the upstream host and allowed request parameters, caps responses at 4 MB and 5,000 features, enforces a 12-second deadline, rejects redirects and changed source contracts, and marks a cap as partial. A response older than five minutes is withheld. The browser refreshes every minute while open and clears displayed points on a failed refresh. Source availability and map rendering remain separate states. This is external observational context, not KFM evidence or an emergency warning service.

The Site application owns these `app/` modules and its same-origin API; this avoids a second catalog or evidence authority. The checked Directory Rules v2 guidance places Site behavior in the existing application and behavior-linked documentation in `docs/`. To roll back this feature, restore the prior Site version or remove the `app/api/lightning/flashes` route and `LightningFlashLoop` mounting; the NASA and NOAA density layers remain independent. Recheck the upstream API contract and the Site owner-private access before any deployment.
