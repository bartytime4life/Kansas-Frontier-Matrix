# Processed RAC region geometry

This lane contains normalized, versioned Kansas Water Office Regional Advisory
Committee planning-area geometry. It is a processed internal product, not a
published map layer.

Coordinates are requested from ArcGIS in WGS 84 longitude/latitude and
preserved without simplification. Feature properties contain only the stable
KFM RAC identity plus source feature ID, name, and abbreviation.

The registry record pins the payload byte count and SHA-256 digest. Validation
does not authorize release or public serving.
