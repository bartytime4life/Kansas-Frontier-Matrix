## Purpose

`data/proofs/proof_pack/atmosphere/` is the Atmosphere/Air specialization of the repository's ProofPack support family. It may hold or index reviewable support bundles for an Atmosphere release candidate, correction candidate, withdrawal candidate, rollback candidate, or other high-burden public-safe derivative.

A bounded Atmosphere ProofPack should make it possible to inspect:

1. the exact claim, layer, API payload, report, tile package, Evidence Drawer payload, Focus Mode scope, graph projection, correction, or rollback under review;
2. the immutable source roles and knowledge-character labels carried by that scope;
3. the admitted source descriptors, evidence bundles, receipts, validation results, policy decisions, catalog records, integrity records, review records, and release dependencies that support it;
4. the spatial, temporal, pollutant, variable, unit, averaging-window, method, QA, calibration, uncertainty, caveat, freshness, and stale-state limits of the support;
5. the exact released carrier proposed, if any, and the correction, withdrawal, invalidation, and rollback path required before public exposure.

This lane does not create Atmosphere truth. It does not issue AQI, health, regulatory, emergency, evacuation, or life-safety guidance. It supports governed review and must yield a finite hold, abstention, restriction, denial, or error when support is incomplete.

## What an Atmosphere ProofPack should contain

A ProofPack should be small enough to review and complete enough to support a bounded decision. Prefer stable identifiers, digests, and resolvable references over copied source payloads.

| Component | Minimum support | Atmosphere-specific burden |
|---|---|---|
| Claim and candidate scope | ProofPack ID, release-candidate reference, artifact kind, audience, intended public surface, geography, time, and exact claims. | Pin pollutant/variable, method, units, averaging window, observation/source/retrieval/model-run/valid/issue/expiry/correction/release times where material. |
| Source closure | SourceDescriptor references, immutable source role, issuing authority, rights, cadence, citation, source head, and stale-state rules. | Distinguish observed sensor, regulatory/archive, public AQI/report, modeled/forecast/reanalysis, remote-sensing proxy, aggregate/climate, advisory context, candidate, synthetic, and restricted context according to the admitted descriptor. |
| Evidence closure | EvidenceRef and EvidenceBundle references, resolution status, claim scope, citations, checksums, and limitations. | Evidence must support the exact knowledge character, pollutant, variable, geography, time, method, and public representation—not merely a related Atmosphere topic. |
| Validation closure | ValidationReport and citation-validation references, validator/profile versions, findings, and finite outcomes. | Exercise AQI/concentration, AOD/PM2.5, model/observation, low-cost-sensor, unit, time, freshness, stale-state, advisory, rights, sensitive-join, and no-network gates where applicable. |
| Transform closure | Run/Transform/Redaction/Aggregation/model/calibration/correction receipt references and input/output digests. | Unit conversion, projection, aggregation, sensor correction, calibration, model fusion, interpolation, and generalization must remain inspectable. |
| Policy and review closure | PolicyDecision, rights/sensitivity result, obligations, steward/reviewer role, review state, and separation-of-duty references. | Low-cost sensors, derived fusion, stale overrides, advisory context, health/regulatory-adjacent language, and sensitive joins require explicit bounded review. |
| Catalog and integrity closure | CatalogMatrix/STAC/DCAT/PROV/domain-catalog references, spec/schema/validator versions, checksums, signatures or Merkle references when required. | Realtime, historical, provisional, corrected, and final collections remain distinct where cadence, rights, freshness, or authority differ. |
| Release dependency | Candidate and proposed release-manifest references without claiming release, plus target carrier IDs/digests. | The release decision stays under `release/`; the ProofPack only supports review. |
| Correction and rollback closure | CorrectionNotice, WithdrawalNotice, RollbackCard, invalidation list, stale/expiry behavior, cache/index propagation, and prior release target where applicable. | Realtime or advisory-adjacent carriers need explicit stale, correction, withdrawal, and rollback behavior before public exposure. |
| Review-support outcome | A finite outcome defined by the accepted ProofPack contract. | The parent README currently proposes review-support states, but the accepted enum and state machine remain `NEEDS VERIFICATION`. |

### Required knowledge-character preservation

The prior README's knowledge-character set is retained as domain guidance:

| Knowledge character | Required interpretation |
|---|---|
| `OBSERVATION` | Direct or QA-qualified measurement with method, units, station/network context, and time scope. |
| `PUBLIC_AQI_REPORT` | Public report/index context; not concentration unless separately supported and labeled. |
| `MODEL_FIELD` | Forecast, reanalysis, simulation, interpolation, or other modeled field; never observation by presentation. |
| `REMOTE_SENSING_MASK` | AOD, smoke plume, cloud/satellite mask, or related proxy/context product; not surface concentration or exposure proof. |
| `CLIMATE_NORMAL_OR_ANOMALY` | Baseline, departure, percentile, or anomaly context with reference period and method; not realtime observation or attribution by itself. |
| `DERIVED_FUSION` | Combined or inferred product with explicit inputs, method, uncertainty, and model role. |
| `ALERT_AND_ADVISORY_CONTEXT` | Official-source referral context with issuer, issue/expiry time, and redirect; not KFM-issued instruction. |

These labels do not replace immutable source role, object-family meaning, evidence support, policy state, review state, or release state.

<a id="4-atmosphere-specific-gates"></a>

## Atmosphere-specific gates

Atmosphere ProofPacks must fail closed when meaning, time, rights, freshness, source role, or public representation is unresolved.

| Gate | Required support | Finite response when missing or unsafe |
|---|---|---|
| AQI versus concentration | Evidence and validation proving that AQI categories/index values are not represented as measured µg/m³, ppb, ppm, or concentration. | `HOLD`, `DENY`, or correction. |
| AOD versus PM2.5 | Proxy/model explanation proving AOD is not represented as surface PM2.5 concentration, exposure, or monitor truth. | `HOLD`, `DENY`, or relabel with limitations. |
| Model versus observation | Model/run identity, initialization, forecast hour, inputs, validation posture, uncertainty, and explicit modeled label. | `ABSTAIN`, `HOLD`, or `DENY` an observed-truth claim. |
| Low-cost sensor posture | Device/network identity, calibration/correction, QA, confidence, caveats, rights, privacy/siting posture, and review. | `RESTRICT`, `ABSTAIN`, `HOLD`, or `DENY`. |
| Units and averaging | Pollutant/variable, canonical/native units, conversion receipt, averaging interval, method, and detection/precision context. | `ERROR`, `HOLD`, or correction. |
| Time validity and freshness | Observation/source/retrieval/model-run/valid/issue/expiry/correction/release times, cadence, stale threshold source, and visible stale state. | `ABSTAIN`, `HOLD`, mark stale, withdraw, or correct. |
| Provisional versus final | Revision state, source version, correction history, and downstream invalidation dependencies. | `HOLD`, label provisional, correct, or withdraw. |
| Advisory context | Official issuer, exact referral source, issue/expiry time, jurisdiction/scope, and redirect language. | `DENY` KFM life-safety wording; provide official-source referral only. |
| Rights and redistribution | SourceDescriptor rights, attribution, redistribution, derivative-use, retention, and policy decision. | `DENY` or quarantine until resolved. |
| Sensitive joins | Policy-approved aggregation/generalization/redaction, transform receipt, re-identification review, and safe public representation for facility, school, hospital, residence, small-population, private-sensor, or infrastructure-adjacent joins. | `DENY`, `RESTRICT`, generalize, aggregate, suppress, or quarantine. |
| Source-role preservation | Immutable role and authority scope from admission through processing, proof, catalog, release, map, graph, export, and AI surfaces. | `HOLD`, `ABSTAIN`, or `DENY` role collapse. |
| Evidence closure | EvidenceRef resolution to EvidenceBundle for every material claim or an explicit unresolved state. | `ABSTAIN`, `HOLD`, `DENY`, or `ERROR`. |
| No-network validation | Synthetic public-safe fixtures and deterministic checks; no live source request in the default validation path. | Validator failure or `ERROR`. |
| Release and rollback | Candidate, review, promotion/release dependency, correction, withdrawal, invalidation, and rollback target. | `HOLD` or `DENY` release review. |

Passing a gate proves only the gate's declared scope. It does not prove Atmosphere truth, medical actionability, regulatory status, emergency authority, release, or publication.

```text
    └── <release_id>.superseded-proof-pack.json
```

Fixtures should normally remain under the accepted fixture roots rather than creating a competing local fixture authority.

<a id="7-lifecycle-relationship"></a>

## Lifecycle relationship

```mermaid
flowchart LR
    SRC["Admitted Atmosphere source<br/>SourceDescriptor + role + rights"] --> RAW["RAW<br/>immutable source capture"]
    RAW --> WORK["WORK / QUARANTINE<br/>normalize, validate, hold"]
    WORK --> PROC["PROCESSED<br/>validated Atmosphere object"]
    PROC --> CAT["CATALOG / TRIPLET<br/>discovery + lineage projection"]
    CAT --> EB["EvidenceBundle<br/>claim-scope evidence closure"]
    EB --> PACK["Atmosphere ProofPack<br/>release-review support"]
    PACK --> CAND["Release candidate<br/>review packet"]
    CAND --> REL["Promotion / Release governance<br/>manifest + decision + rollback"]
    REL --> PUB["PUBLISHED<br/>released public-safe carrier"]

    REC["Receipts<br/>process memory"] -. referenced by .-> PACK
    VAL["Validation reports<br/>declared profiles"] -. referenced by .-> PACK
    POL["Policy decisions<br/>rights · sensitivity · freshness"] -. referenced by .-> PACK
    CORR["Correction / withdrawal / invalidation"] -. referenced by .-> PACK

    PACK -. "never publishes by existence" .-> PUB
```

The ProofPack is a closure aid beside the lifecycle. It does not replace RAW, WORK, QUARANTINE, PROCESSED, CATALOG/TRIPLET, release governance, or PUBLISHED. It must preserve stable references back to those families rather than copying their mutable authority.

## Outputs and downstream handoff

A completed Atmosphere ProofPack may support:

- release-candidate review;
- policy and stewardship review;
- governed API and Evidence Drawer resolution;
- map-layer, tile, API-payload, report, export, graph, or Focus Mode release review;
- correction, withdrawal, supersession, cache invalidation, and rollback analysis;
- audit of source role, knowledge character, time validity, freshness, caveats, and public representation.

It does **not** produce a public answer, public map, AQI service, regulatory result, medical statement, emergency alert, or released artifact by itself.

The handoff order remains:

```text
ProofPack support
  -> independent policy / validation / review closure
  -> PromotionDecision and ReleaseManifest
  -> released public-safe carrier
  -> governed API / UI / map / Evidence Drawer / bounded AI
```

When closure is incomplete, the handoff stops with a finite non-release result.

<a id="8-validation-checklist"></a>

## Validation checklist

Before an Atmosphere ProofPack is used in promotion review, verify all applicable checks and record every non-applicable check with a reason:

- [ ] The ProofPack profile, schema version, validator version, and deterministic identity rule are accepted and recorded.
- [ ] The candidate, artifact kind, exact claim scope, geography, audience, intended public surface, and immutable artifact references are stated.
- [ ] Every source has a SourceDescriptor, immutable source role, issuing authority, rights, cadence, citation, source head, and stale-state posture.
- [ ] Every material claim resolves to an EvidenceBundle or records an explicit finite unresolved outcome.
- [ ] Knowledge-character labels remain explicit and are not silently derived from a filename, map style, provider, or product appearance.
- [ ] AQI is not represented as concentration.
- [ ] AOD is not represented as PM2.5, exposure, or ground observation.
- [ ] Model, forecast, reanalysis, interpolation, and fusion fields are not represented as observations.
- [ ] Low-cost sensor support includes calibration/correction, QA, confidence, caveats, limitations, rights, and review.
- [ ] Pollutant/variable, units, averaging window, method, precision, and conversion receipts are explicit.
- [ ] Observation, source, retrieval, model-run, valid, issue, expiry, correction, release, and stale times are separated where material.
- [ ] Advisory context identifies the official issuer and redirects to official sources without reproducing KFM life-safety instructions.
- [ ] Sensitive joins have policy-approved public-safe transforms and transformation receipts.
- [ ] Validation references cover positive and negative cases for the declared profile.
- [ ] Default validation is deterministic, synthetic, public-safe, and no-network.
- [ ] Receipts are referenced as process memory rather than treated as proof by themselves.
- [ ] Catalog/STAC/DCAT/PROV references preserve discovery and provenance without becoming evidence or release authority.
- [ ] Policy, rights, sensitivity, freshness, review, and release dependencies are explicit and finite.
- [ ] The candidate index and release records are separate from this ProofPack lane.
- [ ] Correction, withdrawal, supersession, invalidation, cache/index propagation, and rollback targets are traceable.
- [ ] Public clients consume only governed APIs or released public-safe carriers.
- [ ] No secret, restricted source term, harmful-precision detail, private access clue, official advisory dump, or control-defeating transform parameter is exposed.

A successful source parse or workflow is not complete validation. No accepted Atmosphere ProofPack validator or producer was established in the bounded inspection.

<a id="9-failure-modes"></a>

## Failure modes

| Failure mode | Why it matters | Required response |
|---|---|---|
| ProofPack duplicates RAW or processed payloads | Collapses proof support with source/canonical data. | Move payloads to the correct lifecycle lane; keep immutable refs and digests. |
| ProofPack acts as ReleaseManifest or PromotionDecision | Collapses proof and release authority. | Move authoritative records to `release/`; retain references only. |
| Receipt is treated as proof | Process memory becomes claim support without closure. | Require EvidenceBundle, validation, policy, review, and release dependencies. |
| Catalog record is treated as evidence or approval | Discovery metadata becomes sovereign truth. | Dereference evidence and keep release decision separate. |
| AQI, concentration, AOD, PM2.5, model, forecast, or sensor roles are flattened | Publishes misleading Atmosphere meaning. | Fail validation; correct source role, knowledge character, claim, and evidence. |
| Advisory context becomes KFM life-safety guidance | KFM impersonates an issuing authority. | Deny the wording; retain official-source referral and scope. |
| Realtime or advisory-adjacent carrier lacks stale/expiry state | Users may treat old context as current. | Hold, label stale, correct, withdraw, invalidate, or roll back. |
| Rights, source role, issuing authority, or redistribution posture is unresolved | Public release may misrepresent authority or violate terms. | Quarantine or deny until resolved. |
| Sensitive facility/population/private-sensor join lacks public-safe transformation | A review bundle becomes an exposure channel. | Restrict, aggregate, generalize, suppress, quarantine, or deny. |
| ProofPack contains no correction, withdrawal, or rollback dependency | Release cannot be safely reversed. | Hold release review. |
| Public client reads this lane directly | Internal proof support bypasses release governance. | Deny direct access; use governed release and API paths. |
| AI summary or map output replaces the ProofPack | Fluent or visual output becomes root truth. | Deny; require released evidence and bounded interpretation. |
| Unknown state is replaced with a plausible default | Uncertainty disappears from the trust path. | Restore `UNKNOWN` or `NEEDS VERIFICATION`; narrow or abstain. |

<a id="10-definition-of-done"></a>

## Definition of done

This sublane becomes operationally usable only when all required criteria are satisfied:

- [ ] An accepted ProofPack semantic contract defines meaning, invariants, finite outcomes, versioning, correction, and supersession.
- [ ] An accepted machine schema defines the canonical ProofPack shape and deterministic identity/digest rules.
- [ ] Valid, invalid, denied, abstained, stale, corrected, withdrawn, and rollback fixture families exist under accepted fixture homes.
- [ ] Atmosphere-specific fixtures cover AQI/concentration, AOD/PM2.5, model/observation, low-cost sensors, units, time, freshness, provisional/final state, advisory context, rights, sensitive joins, and no-network behavior.
- [ ] A deterministic ProofPack producer emits only accepted, reviewable, reference-rich objects and corresponding receipts.
- [ ] A deterministic validator resolves required cross-record references and emits stable finite findings.
- [ ] EvidenceRef-to-EvidenceBundle resolver integrity is tested for positive, missing, stale, conflicted, restricted, withdrawn, and invalidated cases.
- [ ] Policy bundles and negative fixtures fail closed for unresolved rights, source role, freshness, sensitivity, advisory scope, and public representation.
- [ ] CI runs the accepted no-network suite and is graduated deliberately from readiness hold to validated behavior.
- [ ] Accountable owners and independent review requirements are established.
- [ ] At least one synthetic Atmosphere candidate demonstrates source admission → evidence closure → receipts → ProofPack → catalog closure → candidate review → release dry-run → correction/rollback traceability without live source access or public publication.
- [ ] No public client, renderer, export, search, graph, or AI surface reads this lane directly.
- [ ] Correction, withdrawal, cache/index invalidation, and rollback drills restore a prior safe state and preserve audit lineage.

Until then, the correct posture is repository-grounded documentation plus `HOLD`, `ABSTAIN`, `RESTRICT`, `DENY`, or `ERROR` where closure is incomplete.
