## Repository-grounded reconciliation

At the inspected base, KFM already had a stable `promotion-gate` workflow, a proposed `PromotionDecision` shape validator, release fixture/test roots, promotion policy documentation, and a specialized `tools/validators/promotion_gate/` lane. The critical gap was executable behavior:

- `tools/validators/validate_promotion_gate.py` raised `NotImplementedError`;
- `tools/validators/promotion_gate/` contained guidance but no implementation;
- `make publish-check` only printed a TODO; and
- both release workflows asserted that the promotion gate remained a placeholder.

The packet therefore mapped to a nearly finished repository surface rather than a reason to add a new architecture.

| Candidate | Repository overlap | Disposition | Reason |
|---|---|---|---|
| Bounded A-G readiness validator | Partial, with explicit placeholder | `ADAPT / RETAIN` | High user value, deterministic tests, no new dependency, and exact existing homes. |

## Implemented bounded slice

The implementation evaluates a strict, bounded JSON candidate profile with seven visible gates:

| Gate | Bounded check |
|---|---|
| A | Candidate identity, lifecycle posture, release-manifest identity, and stable digest shape. |
| B | Receipt/spec agreement and exact artifact-set digest closure. |
| C | Declared validity, deterministic processing, `EPSG:4326`, and an ordered finite world bbox. |
| D | Parseable UTC effective/recorded intervals and non-inverted boundaries. |
| E | Declared policy profile, known labels, evaluation state, and policy-bundle reference. |
| F | Non-empty evidence, attestation, and STAC/DCAT/PROV references; conditional AI receipt. |
| G | Review presence and author/reviewer separation, rollback target, and correction linkage for supersession. |

The output is deterministic and finite:

| Status | Meaning |
|---|---|
| `PASS` | Declared synthetic closure passed; readiness is `APPROVE_READY` only. |
| `ABSTAIN` | Required support is incomplete without a contradictory or forbidden claim. |
| `DENY` | A declared invariant, integrity condition, policy posture, or review requirement failed. |
| `ERROR` | Input parsing or declared upstream evaluation failed; callers must block. |

Diagnostics expose only stable code, gate, path, and status fields. Candidate values are not echoed. The validator performs no network call and writes no artifact, decision, review, receipt, proof, manifest, or release record.

## Unsafe direct transfers

The following packet material is not promoted:

- `curl`-based dependency installation or unpinned external binaries;
- OIDC, keyless signing, Fulcio, Rekor, OCI publication, or production attestation claims;
- `contents: write`, direct main-branch push, generated commit, or direct publication;
- hard-coded station allowlists, physical ranges, rights labels, reviewer identities, or public-safe claims;
- placeholder, invented, all-zero, or runtime-replaced digests;
- packet directory paths that conflict with current KFM responsibility roots;
- a `PROMOTE` result or any implication that green CI equals accountable approval; and
- sensitive geometry, real source rows, live credentials, or external API access.

## Validation and proof boundary

The dependency-closed batch must prove:

1. one complete candidate reaches only `PASS` / `APPROVE_READY`;
2. missing evidence abstains;
3. identity, artifact, geometry, policy-label, and review failures deny with exact codes;
4. malformed JSON and declared policy-evaluation failure return `ERROR`;
5. AI-mediated work requires an AI receipt;
6. supersession requires correction lineage;
7. duplicate JSON keys and impossible UTC timestamps fail closed;
8. author and reviewer differ;
9. the CLI is deterministic, bounded, and no-network; and
10. both existing release workflows invoke the repository-owned command without gaining write permissions.

Passing these checks is implementation proof for this bounded validator only. It is not source admission, evidence resolution, cryptographic verification, policy approval, human review, release authorization, rollback execution, deployment, publication, or public truth.
