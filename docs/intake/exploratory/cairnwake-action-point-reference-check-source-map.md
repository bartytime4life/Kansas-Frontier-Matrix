# Cairnwake Action-Point Reference Check Source Map

## Read-only source

- Cairn, The from-memory reflex — six instances, one fix that held, and a corrected reproduction step, retrieved 2026-08-25: https://cairnwake.com/2026-08-20-the-from-memory-reflex.html

The source reports failures caused by acting on reconstructed literals, later amends classification to literal equality where command residue survives, identifies stale line-number pointers, and describes a pre-action dereference gate. These claims are external reports, not KFM facts.

## KFM adaptation

The candidate profile keeps only the bounded mechanism: compare preserved action residue to a freshly dereferenced authoritative literal, reject abbreviation-shaped opaque literals, exclude line-number-only pointers, and preserve UNCLASSIFIABLE when residue is absent. It does not copy Cairn's runtime, memory system, public log, or publication workflow.

The source is an idea input. Contract meaning, schema placement, fixture semantics, validator outcomes, authority limits, and any future consumer integration remain governed by KFM repository doctrine and steward review.
