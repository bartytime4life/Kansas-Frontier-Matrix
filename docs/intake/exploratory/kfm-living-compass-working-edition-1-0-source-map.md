## Highest-confidence mined ideas

1. **Use COMPASS as a question set before using it as a score.** Each dimension
   can expose a missing dependency, while any unresolved hard gate remains
   visible instead of being averaged away.
2. **Offer a bounded proof-session worksheet.** A contributor should leave with
   a claim, intended user value, evidence references, policy questions,
   validation result, unresolved items, and a safe rollback—not a declaration
   that the feature is proven or release-ready.
3. **Use the five-session rhythm as work organization, not lifecycle law.** Map
   its outputs onto current owning artifacts and finite outcomes instead of
   creating new state names.
4. **Select one lighthouse mission at a time.** The safest candidate is the one
   whose source identity, rights, sensitivity, evidence, policy, public-safe
   representation, correction, and rollback can close with the fewest new
   authority decisions.
5. **Make every demonstration disclose its proof boundary.** A polished map,
   card, or rehearsal should state what was tested, what remains unknown, and
   which public or operational effects are still denied.

## Unsafe direct transfers

| Source pattern | Why direct transfer is unsafe | Required correction |
|---|---|---|
| Treat the COMPASS total as a promotion threshold | A high aggregate can hide a failed evidence, rights, sensitivity, policy, review, or rollback gate. | Keep hard gates explicit and fail closed; use the rubric only for planning until separately adopted. |
| Treat a 90-minute result as “proof” | A timebox says how work was organized, not whether the claim or implementation is valid. | Record exact scope, inputs, tests, findings, limitations, and non-effects. |
| Replace current finite vocabularies with the DOCX set | The set combines placement, runtime, policy, and workflow concepts. | Preserve each owning lane's accepted vocabulary and define translations only through an accepted decision. |
| Cite the DOCX for current Directory Rules status | Its pre-adoption statement is stale. | Cite ADR-0029 and the adopted Directory Rules. |
| Start a lighthouse mission from a compelling narrative | A narrative does not establish source admission, evidence, rights, sensitivity, policy, release, or public safety. | Freeze authority, choose one bounded claim, and close its dependencies in order. |
| Let rehearsal or visual polish strengthen a claim | Demonstration quality is not evidentiary quality. | Keep the Evidence Drawer, limitations, abstention, correction, and rollback visible. |

## Recommended next bounded action

Prepare a **decision-only COMPASS crosswalk** before adding a score, workflow,
template, or automation. It should:

- map every rubric dimension to the existing artifact or reviewer that owns it;
- identify which dimensions are hard gates and therefore cannot be averaged;
- keep accepted placement, policy, runtime, review, and release vocabularies
  separate;
- compare `RETAIN_AS_QUESTIONS`, `ADOPT_QUALITATIVE_CHECKLIST`,
  `EVALUATE_SCORING`, and `DENY_AUTHORITY_EFFECTS` outcomes;
- use one synthetic, no-network example; and
- authorize no source admission, policy decision, review approval, promotion,
  deployment, release, or publication.

This intake record does not create that decision.
