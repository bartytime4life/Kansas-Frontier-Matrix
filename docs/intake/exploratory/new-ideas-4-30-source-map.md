## Directory Rules and authority basis

The accepted [Directory Rules v2](../../doctrine/directory-rules.md), adopted through [ADR-0029](../../adr/ADR-0029-adopt-directory-governance-standard-v2.md), place artifacts by responsibility root, lifecycle, authority, exposure, mutability, and retention rather than by a packet's suggested tree.

| Packet material | Correct responsibility if later promoted |
|---|---|
| Exploratory packet identity, clustering, and disposition | `docs/intake/` |

| Human-readable object meaning | `contracts/` |

| Executable validators, probes, and comparison tools | `tools/` |
| Reusable implementation | `packages/` |
| Source adapters | admitted connector root and domain/source lane |

Packet paths such as generic `schemas/`, `policy/`, `ci/`, `batches/`, `downloads/`, `out/`, or source-specific trees are not carried forward as current KFM locations. Existing responsibility roots and accepted placement decisions control implementation.

## Unsafe direct transfers

| Packet pattern | Why direct transfer is unsafe | Required correction |
|---|---|---|
| “Repo-ready” source trees, loaders, policies, validators, and workflows | The repository already has stronger or conflicting homes and object families. | Re-derive from current contracts and Directory Rules; implement one dependency-closed gap. |
| A download or API query without a normalized query snapshot | Returned bytes cannot prove requested scope, exclusions, pagination closure, or sampling behavior. | Preserve RetrievalIntent, QuerySnapshot, source descriptor version, and secret-free receipt. |
| A general “public domain” or license label | Dataset-level terms, access agreements, attribution, redistribution, and commercial-use limits may differ or drift. | Bind an evidence-backed terms snapshot and rights assessment to the retrieval. |
| Missing distribution row treated as absence | Coverage, assessment, suppression, source vintage, and boundary mismatch can all produce blanks. | Use a closed distribution-status and coverage vocabulary; abstain on unsupported absence. |
| County score treated as biodiversity richness | Opportunistic sampling and prior investment can dominate record counts. | Separate effort, density, recency, gaps, source roles, uncertainty, and work-priority meaning. |
| Silent unit, depth, time-window, footprint, or resolution harmonization | Comparable-looking values can retain incompatible support and knowledge character. | Emit a UnitTransformReceipt and ScaleReconciliationReport or return an unsupported outcome. |
| Hard-coded source cadence or latency from packet prose | Product delivery behavior changes and differs from observation cadence. | Verify official product facts and version a DeliveryExpectation separately from observations. |
| Partial or resumed transfer treated as the final artifact | Incomplete bytes can enter processing, retries can double-ingest, and provider jobs can expire or be replaced. | Quarantine partial state; bind checkpoints, final size, digest, and idempotent ingest identity. |
| `npm ci || true`, signing with `|| true`, or placeholder Merkle roots | These patterns hide dependency or attestation failure and can report a green path without proof. | Fail closed; use pinned dependencies, real verification, deterministic fixtures, and finite error outcomes. |
| Signature or digest equals truth or release | Integrity and signer identity do not prove evidence, rights, sensitivity, review, or publication approval. | Keep proof, evidence, policy, review, release, correction, and rollback independent. |
| Public wildcard CORS, mutable object keys, or in-place PMTiles replacement | Cache and identity drift can serve mismatched or withdrawn bytes. | Use versioned immutable release identities and cache-invalidation/withdrawal receipts. |
| Offline cache trusted indefinitely | Corrections, withdrawals, policy changes, and expiry cannot reach a disconnected client immediately. | Surface last-verified time and expiry; block consequential use when trust freshness is outside policy. |
| Decode or render before integrity verification | Unverified bytes may flash, execute expensive decode paths, or exhaust resources. | Verify released bytes and proof binding within declared budgets before render. |
| Packet vegetation thresholds treated as universal science | Thresholds depend on sensor, biome, season, mask, objective, validation, and policy. | Use versioned source-specific fitness profiles and synthetic negative fixtures first. |
| Cesium overlay code as architecture authority | A code sample cannot override the accepted MapLibre renderer boundary or admit dependencies. | Retain renderer-neutral concepts and route any renderer change through a separate accepted decision. |
| Real species, people, DNA, coordinates, tokens, API keys, or credentials in examples | Examples can expose sensitive facts, normalize unsafe fixtures, or leak secrets. | Use synthetic non-joinable records and secret references only. |

## Dependency-ordered continuation

### Wave 1 - meanings and decisions

1. Define retrieval intent, normalized query snapshot, and secret-exclusion rules.
2. Define terms snapshot, rights reassessment, and downstream terms-drift disposition.
3. Define sampling effort, detection opportunity, non-detection, distribution state, and coverage semantics.
4. Define MeasurementSupport, conversion/resampling profiles, and comparison-fitness outcomes.
5. Define product cadence, expected delivery latency, actual availability, and staleness separately.
6. Define offline trust expiry, correction, withdrawal, and verify-before-render boundaries.

### Wave 2 - bounded offline proof

After the applicable Wave 1 decision closes, admit at most one dependency-closed proof:

- synthetic RetrievalIntent/QuerySnapshot normalization and secret-leak rejection;
- synthetic distribution states proving that missing rows do not become absence;
- paired synthetic sampling-event and observation fixtures proving supported non-detection;
- synthetic county aggregates comparing density-led and coverage-gap-led priority scores;
- synthetic grid/station MeasurementSupport reconciliation with unit and scale mismatches;
- synthetic delayed product and interrupted async transfer state-machine fixtures;
- synthetic OfflineReleaseCapsule install, expiry, correction, withdrawal, and rollback;
- synthetic VerifiedRenderingEnvelope corruption, timeout, memory-budget, and cancellation cases; or
- synthetic vegetation observations with confounder masks and correction lineage.

### Wave 3 - source-specific adapters

Live USDA PLANTS, eBird, GBIF, NASA SMAP, Mesonet, AirNow, AQS, NHDPlus, remote-sensing, cloud-hosting, signing, or other integrations remain later work. Each requires:

- current official-source verification;
- admitted source descriptors;
- source-role, rights, terms, access, cadence, and sensitivity review;
- approved credentials and dependency handling;
- query, transfer, measurement, and correction receipts where applicable;
- review, release, rollback, and cache/withdrawal behavior; and
- separate exact authorization.

### Recommended next bounded action

**PROPOSED:** start with a contract-only `DistributionAssertion` and `CoverageAssessment` decision slice plus synthetic `present`, `explicitly_absent`, `not_assessed`, `unknown`, `suppressed`, `stale`, and `missing_row` fixtures.
