> [!CAUTION]
> This is a sensitive domain. Do not place real living-person identifiers, DNA or genomic material, raw kit or vendor identifiers, private relationship data, exact private locations, protected cultural information, disputed title material, or proprietary source excerpts in Git, pull requests, issues, CI logs, fixtures, screenshots, or public artifacts.

> [!IMPORTANT]

A passing workflow does not establish a real person's identity, kinship, consent, rights, DNA support, title, boundary, EvidenceBundle closure, active policy runtime, operational readiness, release approval, or public-use safety.

## Inputs and outputs

### Required inputs

- Exact repository revision and affected paths.
- Named purpose, audience, data class, exposure class, and proposed action.
- Resolved source role, rights, provenance, sensitivity, consent, living-person, sovereignty, harmful-precision, and retention posture.
- Exact applicable contracts, schemas, policy versions, evidence references, and review requirements.
- Synthetic fixtures for repository-visible validation; no real sensitive payloads.
- Named rollback, revocation, correction, or containment path when the action could affect exposure.

### Permitted outputs

- A finite `PASS`, `HOLD`, `ABSTAIN`, `DENY`, `ERROR`, `ROLLBACK`, or `ESCALATE` result with exact revision and reason.
- A minimized reviewer handoff that contains no sensitive payload values.
- Links to test or workflow evidence at the tested SHA.
- A documentation correction or draft pull request that does not activate sources, mutate data, approve policy, release, deploy, or publish.

Authorized repository contributors may edit these documents through the normal reviewed Git workflow. That permission does not make an editor a privacy, consent, sovereignty, legal, policy, evidence, release, or publication authority.

## Exposure, mutation, and retention

- Treat this documentation as repository-visible. Record classifications, opaque references, reason codes, and minimized summaries—not sensitive values.
- Living-person and DNA-derived exposure fails closed. Unknown living status, unclear consent, disputed rights, sovereignty concerns, or harmful precision produces `HOLD`, `ABSTAIN`, `DENY`, or `ESCALATE`, never implied approval.
- Assessor and tax records remain administrative observations, not title truth. Parcel geometry remains context, not legal-boundary proof.
- Repository-visible tests use synthetic fixtures only. Do not copy real source payloads into a fixture to make a test pass.
- Preserve Git history and correction lineage. A documentation edit or revert does not revoke consent, delete a source record, withdraw a release, invalidate a cache, or reverse an operational action.
