> [!CAUTION]
> This is a sensitive domain. Do not place real living-person identifiers, DNA or genomic material, raw kit or vendor identifiers, credentials, private relationship data, exact private locations, protected cultural information, disputed title material, or proprietary source excerpts in Git, pull requests, issues, CI logs, fixtures, screenshots, tabletop records, or public artifacts.

> The strongest current executable evidence remains **two deterministic, no-network synthetic consent profiles**. The dedicated revocation runbook reviews one of those profiles; it does not add a third profile or prove a real action occurred. ## Inputs and permitted outputs

### Required inputs

- Exact repository revision and affected paths.
- Named purpose, audience, data class, exposure class, and proposed action.
- Resolved source role, control, rights, provenance, sensitivity, consent, living-person, sovereignty, harmful-precision, custody, and retention posture.

- Synthetic fixtures or fictional metadata only.
- Named correction, revocation, withdrawal, containment, erasure, release, or rollback owner when exposure could change.

### Permitted outputs

- A procedure-bounded `PASS`, `FAIL`, `NOT_RUN`, `HOLD`, `ABSTAIN`, `DENY`, `ERROR`, or `ESCALATE` result with exact revision and reason.
- A minimized reviewer handoff without sensitive values or real vendor/account details.
- Links to test or workflow evidence at the tested SHA.
- A documentation correction or draft pull request that does not activate sources, access vendors, mutate data, approve policy, execute cleanup, release, deploy, or publish.

Repository contribution permission is not privacy, consent, sovereignty, legal, source, custody, security, policy, evidence, operations, release, or publication authority.

## Exposure, mutation, and retention

- Treat repository documentation and tabletop results as repository-visible. Record classifications, opaque synthetic references, reason codes, and minimized summaries—not protected values.
- Unknown living status, unclear consent, disputed rights, unresolved vendor control, sovereignty concerns, harmful precision, custody uncertainty, or retention ambiguity fails closed.
- Vendor loss does not authorize emergency bulk download, custody transfer, indefinite retention, silent deletion, or public use.
- Revocation does not automatically choose tombstone, deletion, erasure, correction, withdrawal, release replacement, or rollback.
- Assessor and tax records remain administrative observations, not title truth. Parcel geometry remains context, not legal-boundary proof.
- Preserve Git and correction lineage. A documentation edit or revert does not revoke consent, delete data, contain an incident, withdraw a release, invalidate a cache, or reverse an operational action.
