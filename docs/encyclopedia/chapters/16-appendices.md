## Chapter maintenance checklist

1. Verify the repository or source version supporting the change.
2. Read the owning document and preserve its exact identifiers and limitations.
3. Make the chapter useful for a specific reader question.
4. Keep links relative to this file and preserve existing anchors where applicable.
5. Distinguish original observations, models, interpretations and display context.
6. Validate changed links and metadata, then review the diff for unsupported claims.
7. Record the update in the [changelog](../CHANGELOG.md) without rewriting past events.
