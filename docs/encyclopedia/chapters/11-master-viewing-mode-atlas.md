# Master viewing-mode atlas

Evidence snapshot: `main@ebcc4988a08a3b96d10ee65ae9b4b09a37af5ebe`. Draft reference; formal lane acceptance remains pending.

Choose the view that answers the question, then inspect the source and time semantics that the view can hide. View names describe research patterns; the linked feature guides determine which controls the current Site actually implements.

| Viewing pattern | Good question | Required visible context | Typical misreading |
|---|---|---|---|
| Plan map | Where is the selected feature? | Source, scale, date and geometry role | Screen precision mistaken for source accuracy |
| Time playback | What changes across supported frames? | Valid time, interval and missing frames | Smooth playback mistaken for continuous observation |
| Side-by-side comparison | How do two documented states differ? | Both source editions and aligned support | Color differences mistaken for measured change |
| Cutaway | How do surface and recorded intervals relate? | Vertical units, source coverage and interpretation | Interpolation mistaken for observed geology |
| Evidence inspection | What supports this selected claim? | Source identity, role, lineage and uncertainty | All drawer content treated as admitted evidence |
| Report/story draft | How can an investigation be explained? | Citations, dates, caveats and persistence scope | Saved draft mistaken for reviewed publication |

## Choosing a mode

For a current water question, start with observations and the supported temporal window before adding forecast context. For a historic map comparison, identify each edition and its georeferencing limitations before comparing features. For subsurface questions, start with records and their depth/elevation basis before interpreting a continuous form.

## Acceptance checks

Inspect empty, partial and loading states as well as a successful view. Check keyboard navigation, small-screen layout and the labels exposed to assistive technology. Verify that changing time, selection or source does not leave stale details presented as current. If a view cannot provide exact coverage or observation time, its uncertainty must remain visible.

Use [history comparison](../../../apps/site/source/docs/history-comparison.md), [cutaway detail](../../../apps/site/source/docs/cutaway-surface-detail.md), and [map research tools](../../../apps/site/source/docs/map-research-tools.md) for the concrete feature behavior. This chapter does not establish browser acceptance by itself.
