# Executive summary

Evidence snapshot: `main@ebcc4988a08a3b96d10ee65ae9b4b09a37af5ebe`. Draft reference; formal lane acceptance remains pending.

KFM combines Kansas-focused exploration with a governed path for making inspectable claims. The Explorer offers map context and research tools; the repository contains contracts, validators, fixture demonstrations, source adapters, and local data operators. These components have different maturity levels.

## Three practical workflows

1. **Explore:** select an area, inspect source and time labels, compare views, and retain an explanation of the displayed limitations. Start at the [Explorer guide](../../../apps/site/source/README.md).
2. **Preserve data:** identify an explicit source selection, preview space and transfer bounds, capture into the external local store, and verify the bytes and receipts. Start at [local data operations](../../runbooks/local-pc-data-store.md) and [free acquisition](../../runbooks/free-data-acquisition.md).
3. **Build evidence:** trace a candidate through its source, semantic contract, schema, policy, validation, review, and release records. Start at [first governed PR](../../runbooks/FIRST_GOVERNED_PR_RUNBOOK.md).

## Current capability boundary

| Surface | Useful today | Evidence still required for stronger claims |
|---|---|---|
| Site source mirror | Map, time, comparison, underground, source-context and research implementations documented in the source tree | Exact deployed source and browser acceptance for hosted behavior |
| Local data tools | Bounded acquisition, private capture, inventory and integrity workflows | Selected-source admission and operational acceptance |
| Domain libraries and tests | Mixed implementation, synthetic validators, contracts and planning | Domain-specific coverage; a directory alone is insufficient |
| Documentation systems | Searchable explanation, chronology and navigation | Code/release evidence for implementation and lifecycle claims |

A productive investigation records the question, area, time interval, source role, exact product/version, exclusions, and uncertainty. For example, a water-level point, discharge observation, watershed boundary, and modeled flow field may be shown together, but each keeps its original meaning. Spatial coincidence does not make them interchangeable or establish causation.

The next chapters turn these distinctions into operating procedures, comparison tables and review criteria. They do not claim that all planned domains have running ingestion or public products.
