# Brown County — Focus Mode

> **Purpose.** Orient maintainers to the Brown County planning lane, make its sovereignty, cultural-authority, water, ecology, property, agriculture, geology, transportation, and historical-context boundaries visible, and route future work through KFM evidence, policy, review, release, correction, and rollback controls.

> [!IMPORTANT]
> **Tracked planning artifacts are not implementation or release evidence.** This directory contains this README and one Brown County build plan. Their presence prevents accidental duplicate planning; it does not establish source admission, semantic correctness, validator success, runtime behavior, qualified review, release, deployment, or publication.

> [!CAUTION]
> **Placement remains unresolved.** This same-path update repairs an existing README under `docs/focus-mode/counties/brown_county/`. Accepted Directory Rules v2 treats Focus Mode as a composition scope; proposed ADR-0027 describes a different plural, kebab-case control plane but remains unaccepted. No file is moved, renamed, copied into a parallel tree, or declared the final canonical county write target here.

> [!WARNING]
> **Nation authority and sensitive-location restraint are first-order boundaries.** The build plan combines ordinary county context with sovereign Nation, cultural, ecological, property, water, infrastructure, and historical subjects. Exact or inferable sacred, ceremonial, burial, archaeological, sensitive ecological, private-property, land-status, or infrastructure-vulnerability information must not reach an ordinary public client. Missing evidence, rights, authority, safe resolution, policy, review, or release closure must produce a bounded `ABSTAIN`, `DENY`, or `ERROR` rather than a fluent inference.

## 4. Proposed Brown County proof slice

The build plan proposes a public-safe county evidence view centered on official Nation source routing, county orientation, public water-monitoring context, public conservation and recreation places, aggregate agriculture, geology and ground-water interpretation, transportation references, and bounded historic-register context. Its distinctive thesis is **sovereignty first**: county-scale composition must not convert Nation-authored public material, county GIS, adjacent records, or generated language into cultural authority, land-status truth, or sensitive-location disclosure.

| Proposed element | Evidence needed before reliance | Non-effect of this README |
|---|---|---|
| Brown County and municipal orientation | Registered authoritative geography source, vintage, geometry identity, rights, and released public-safe carrier | Does not declare a current boundary artifact or public layer |
| Official Nation source routing and public context | Current Nation-authored or otherwise authoritative public source, permitted claim scope, authority-to-control posture, rights, qualified review, and safe representation decision | Does not create cultural meaning, infer consent, map a Nation boundary, or authorize derived cultural geography |
| County GIS and administrative mapping | Verified official source identity, access terms, rights, freshness, field-level sensitivity, and permitted transform role | Does not admit, scrape, mirror, or publish county GIS data |
| Parcel, ownership, reservation, trust, or land-status context | Authoritative legal source, purpose limitation, living-person and property policy, field minimization, Nation/federal authority where applicable, and anti-inference tests | Does not make title, ownership, trust-status, reservation-boundary, access-right, or named-person assertions |
| Public water-monitoring context | Validated station identity, parameter, timestamp, revision/freshness posture, source role, and limitations | Does not provide drinking-water, hazard, compliance, water-right, or legal conclusions |
| Public conservation and recreation context | Admitted public administrative source, approved geometry, rights, sensitivity review, and no-occurrence-inference tests | Does not imply sensitive species, habitat, management, or survey locations |
| Aggregate agriculture | Admitted aggregate source, measure definitions, reporting year, suppression posture, and anti-reidentification review | Does not authorize farm, operator, household, or parcel inference |
| Geology and ground-water background | Appropriate scientific source role, scale, publication date, temporal scope, rights, and educational limitations | Does not describe live conditions, current safety, engineering fitness, or regulatory state |
| Transportation context | Current public source, date/status, corridor scale, stale-state handling, and operational-sensitivity review | Does not provide live routing, work-zone operations, enforcement, or vulnerability analysis |
| Registered historical resource context | Registry authority, rights, listed/action date, public claim scope, cultural review trigger, and correction path | Does not become culturally comprehensive history, archaeology proof, or land-right evidence |
| Map and AI interpretation | Released public-safe carriers, resolvable EvidenceBundles, finite policy outcomes, governed runtime, correction, and rollback support | Does not create a layer, route, model capability, or public answer |

The plan recommends a verification-and-documentation first slice before source descriptors, contracts, fixtures, mock UI, or release rehearsal. This README performs only the same-path orientation portion of that planning step. It creates no source descriptor, fixture, payload, policy decision, release manifest, correction notice, or rollback record.

## 5. Source-role and cross-domain boundaries

The build plan names several source families that answer different questions. They must not be merged into one undifferentiated county truth layer.

| Planned source or object class | Legitimate bounded role | Must not be treated as |
|---|---|---|
| Nation-authored or official Nation public source | Source-specific public identity, program, history, natural-resource, or routing context within the Nation's stated public scope | Generic county heritage, inferred cultural meaning, automatic reuse consent, comprehensive land status, or derived sensitive map authority |
| State Native American affairs or public directory source | Public routing and high-level government context within its explicit scope | Substitute for Nation authority, consent, cultural review, or authoritative geometry |
| County GIS or public online map | Source discovery, administrative orientation, and candidate geometry or attribute inventory after rights review | Automatic reuse permission, title authority, trust/reservation status, access entitlement, evidence closure, or public release |
| Federal monitoring or observation source | Identified station and validated timestamped observations | Safety advice, legal allocation, compliance determination, or unqualified present condition |
| State conservation administration | Public conservation/recreation location and administrative context | Sensitive occurrence, habitat, survey, or management truth beyond source scope |
| Federal statistical aggregate | County-level statistics for a stated reporting period | Individual farm, operator, household, parcel, or ownership assertion |
| State scientific interpretation | Published geology, geomorphology, or ground-water background with visible scale and date | Live monitoring, current hazard, engineering, or regulatory finding |
| State transportation reference | Public corridor and dated project or map context | Live routing, enforcement, security, active-operations, or vulnerability intelligence |
| Historic registry record | Registered property and documented registry claim scope | Comprehensive community history, culturally authoritative interpretation, archaeological inventory, or land-right conclusion |
| Generated narrative | Plain-language explanation of already admissible evidence | Evidence, source authority, Nation authority, policy decision, review, consent, or release state |

### Cross-source combination rule

Juxtaposition is not proof. The system must not infer cultural meaning, land status, environmental condition, ownership, causation, access, safety, or present-tense state merely because separate source cards appear in the same county view. Every combined claim needs an explicit relation, evidence support, spatial and temporal scope, policy decision, and release posture appropriate to its significance.

## 6. Public safety, sovereignty, and governed outcomes

### Fail-closed matrix

| Request or condition | Required public outcome | Boundary |
|---|---|---|
| Exact or inferable sacred, ceremonial, burial, archaeological, or culturally restricted place | `DENY` | Do not confirm existence or expose location through map, text, metadata, search, telemetry, accessibility output, cache, or export |
| Exact sensitive species, habitat, survey, or Nation-linked ecological location | `DENY` unless an accepted public-safe transform and qualified review explicitly permit the operation | Public availability of a report is not blanket permission for derived precision |
| Cultural meaning or community interpretation generated from nearby records | `ABSTAIN` or `DENY` | Require Nation-authoritative public material and qualified review; generated synthesis cannot stand in |
| Parcel or county GIS used to infer trust land, reservation boundary, title, ownership, access, or a named person | `ABSTAIN` or `DENY` | Administrative mapping does not carry legal, Nation, or living-person authority |
| Monitoring record used to answer drinking-water, flood-safety, compliance, water-right, or legal-status question | `ABSTAIN` | Observation source role does not support the requested operational or legal conclusion |
| Public conservation place used to imply sensitive occurrence or habitat | `ABSTAIN` or `DENY` | Administrative place context and ecological evidence remain separate |
| Infrastructure or transport vulnerability request | `DENY` | Ordinary public Focus Mode is not a vulnerability-analysis surface |
| Material claim lacks a resolving EvidenceRef-to-EvidenceBundle chain | `ABSTAIN` | Cite-or-abstain |
| Policy, evidence resolver, validator, or governed runtime fails | `ERROR` | Never fallback to an answer or a less restrictive display |
| Evidence, policy, review, and release closure supports the exact bounded public operation | `ANSWER` | Include citations, source roles, time basis, limitations, release/correction state, and public-safe precision |

### Public client boundary

A future Brown County client may consume only governed finite envelopes and released public-safe artifacts. It must not read:

- RAW, WORK, QUARANTINE, or internal candidate stores;
- unrestricted source payloads or direct source-system responses;
- protected cultural, ecological, property, person, land-status, or infrastructure records;
- direct model output;
- policy internals or sensitive denial reasons;
- unreleased receipts, proofs, review notes, or release candidates.

A refusal is part of the trust surface. Public explanations should say that information is unavailable or withheld under the applicable public-safety boundary without revealing whether a protected record exists or how a protection transform works.

## 8. Smallest safe follow-up

The next dependency-closed implementation should remain narrower than a live county feature.

1. **Recheck path and control-plane authority.** Keep the current lane stable unless ADR-0027 or a successor is accepted with migration evidence.
2. **Recheck source identity and rights.** Build a dated review packet for the plan's candidate Nation, county, state, and federal source families; do not fetch, ingest, or publish payloads.
3. **Identify qualified decision roles.** Record the Nation, cultural, rights, sensitivity, evidence, security, and release review responsibilities required for each proposed operation without inventing people or approval.
4. **Define one no-network assessment profile.** Use synthetic, non-sensitive references to prove source-role separation, evidence gaps, exact-location denial, parcel/land-status abstention, monitoring-authority abstention, and fixed non-effects.
5. **Keep public runtime work on HOLD.** No Brown County route, map layer, governed AI answer, release, deployment, or publication should follow until contracts, machine shape, policy, evidence resolution, qualified review, correction, and rollback close.

A useful first executable slice would prove that an exact-sensitive-location request is denied, an unsupported cultural or land-status inference abstains, a public-source routing card carries no geometry, and every effect flag remains false. It would not admit or retrieve a live source.
