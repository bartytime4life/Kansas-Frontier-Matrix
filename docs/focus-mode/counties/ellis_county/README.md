# Ellis County Focus Mode

> **Purpose.** Orient maintainers to the Ellis County planning lane, make its
> water-currentness, private-well/property, scientific-locality, and
> flood-property boundaries visible, and route future work through KFM source,
> evidence, policy, review, release, correction, and rollback controls.

> [!IMPORTANT]
> **Tracked planning artifacts are not implementation or release evidence.**
> This directory contains this README and one Ellis County build plan. Their
> presence prevents accidental duplicate planning; it does not establish source
> admission, semantic correctness, validator success, regulatory status,
> runtime behavior, release, deployment, or publication.

> [!CAUTION]
> **Placement remains a compatibility question.** This same-path update repairs
> an existing README under `docs/focus-mode/counties/ellis_county/`. Accepted
> Directory Rules v2 governs placement; proposed ADR-0027 describes a plural,
> kebab-case control plane but remains unaccepted. No file is moved, renamed,
> copied into a parallel tree, or declared canonical here.

> [!WARNING]
> **A dated public water notice is not an individual well or compliance
> decision.** The build plan proposes municipal water-conservation context,
> public GIS, geology, natural-history, agriculture, and flood routing. KFM must
> not use those surfaces to decide whether a person, address, parcel, well, or
> activity is governed, compliant, exempt, safe, insurable, or legally entitled;
> expose owners, addresses, private wells, or fossil localities; or infer
> collecting access, mineral rights, or property status. Missing evidence,
> authority, currentness, rights, safe resolution, policy, or review closure
> must produce a bounded `ABSTAIN`, `DENY`, or `ERROR`.

## 4. Proposed Ellis County proof slice

The build plan proposes a public-safe county evidence cockpit centered on
Hays-area water-conservation context, source-currentness and regulatory-role
separation, county-scale agriculture, public geology and natural-history
education, and official floodplain routing. It treats accessible GIS and
scientific sources as a governance test: discoverability is not source
admission, redistribution permission, individual applicability, public safety,
or authority for every downstream inference.

That is a **planning thesis**, not a verified current product.

| Proposed element | Evidence needed before reliance | Non-effect of this README |
|---|---|---|
| County and Hays orientation | Registered authoritative geography source, vintage, geometry identity, rights, and released public-safe carrier | Does not declare a current boundary artifact or public layer |
| Dated water-conservation notice context | Current official source identity, notice and operative dates, source role, controlling-authority record, supersession checks, rights, policy, review, and release evidence | Does not decide whether a well, address, person, business, or activity is currently governed, compliant, exempt, or enforceable |
| IGUCA and regulatory context | Direct controlling authority where required, temporal scope, limitations, and distinct municipal/state source roles | Does not turn a municipal notice into a complete regulatory record or water-right determination |
| Public GIS and appraisal context | Dataset-specific authority, rights, public-record limits, privacy, allowed use, correction behavior, and approved public-safe geometry | Does not authorize owner, name, address, title, appraisal, private-well, tax, or compliance joins |
| KGS geology and Sternberg natural-history context | Admitted scientific and institutional sources, scale, rights, interpretation limits, locality sensitivity, and review | Does not expose fossil sites, authorize collection or access, establish mineral rights, or prove property or hazard conclusions |
| Agriculture at county scale | Admitted aggregate source, definitions, vintage, transform lineage, privacy review, and citations | Does not authorize farmer, parcel, private-well, production, conduct, or liability inference |
| Floodplain routing | Current official routing source, date, limitations, policy, and high-stakes non-determination UX | Does not provide parcel flood status, insurance, permitting, elevation, engineering, or safety advice |
| Map and AI interpretation | Released public-safe carriers, resolvable EvidenceBundles, finite policy outcomes, governed runtime, correction, and rollback support | Does not create a layer, route, model capability, refreshed status, or public answer |

Do not copy source payloads, sensitive locations, individual property records,
or proposed machine objects into this directory to simulate completion. The
county lane should reference governed objects in their owning roots only after
those objects exist and are reviewable.

## 5. Public safety and governed outcomes

| Request or output class | Bounded posture | Reason |
|---|---|---|
| Released, broad, time-labeled county context with resolving citations | `ANSWER` only when evidence, policy, review, and release conditions pass | Keeps the result within admitted public-safe evidence |
| Missing, stale, conflicting, superseded, overly coarse, or unresolvable evidence | `ABSTAIN` | Fluency cannot substitute for evidence, source role, or currentness |
| Individual well, address, parcel, resident, business, use, compliance, exemption, enforcement, water-right, or legal-applicability question | `DENY` and route to the responsible current authority | KFM is not the regulatory or individual-facts decision maker |
| Owner, name, address, appraisal, title, tax, private-well, or regulatory-targeting join | `DENY` | Public availability does not authorize aggregation, targeting, or unsafe reliance |
| Precise or reconstructive fossil, scientific collection, archaeological, sacred, burial, or private-land target | `DENY` | Scientific, cultural, property, and access sensitivity require fail-closed handling |
| Geologic or museum context used to infer collecting access, excavation permission, mineral rights, title, hazard, or engineering fitness | `DENY` or `ABSTAIN` | Scientific and institutional sources do not own those decisions |
| Aggregate agriculture used to identify a farm, well user, regulated party, violation, or responsibility | `DENY` | Aggregate statistics are not person, parcel, or conduct evidence |
| Property flood status, insurance need, permit result, elevation, engineering, or immediate safety guidance | `DENY` or `ABSTAIN` and route to the responsible authority | A routing surface is not an individual high-stakes determination |
| Dynamic drought, municipal supply, emergency, drinking-water, road, or public-health status without current authoritative support | `ABSTAIN` | Dated context cannot silently become live operational guidance |
| Cross-source inference of causation, current status, regulatory scope, ownership, property condition, or legal responsibility | `DENY` or `ABSTAIN` | Distinct contextual sources do not jointly prove the inferred claim |
| Resolver, policy, carrier, citation, or runtime failure | `ERROR` with no unsupported fallback claim | Failure must remain visible and fail closed |

Client-side hiding is not a sensitivity control. Protected detail must not be
delivered to an ordinary public client, included in public logs or analytics,
or reconstructed from tiles, filters, search, exports, caches, identifiers, or
AI responses.

## 6. Evidence and readiness boundary

An Ellis County public result must remain downstream of the governed KFM path:

1. identify a source once in the source-authority surface and preserve its
   distinct role;
2. review authority, rights, access, time, geography, privacy, scientific
   sensitivity, allowed claims, prohibited inference, and correction behavior;
3. admit candidate material to `RAW`, or hold it in `WORK / QUARANTINE` when
   requirements are unresolved;
4. derive and validate `PROCESSED` material with transform and provenance
   lineage;
5. resolve every consequential `EvidenceRef` to an `EvidenceBundle` and apply
   policy;
6. make a separate promotion and release decision with correction and rollback
   targets;
7. serve only released public-safe artifacts through governed interfaces;
8. keep map rendering and AI interpretation subordinate to that evidence and
   decision state.

## 7. Smallest safe follow-up

The smallest legitimate follow-up is a **planning-evidence reconciliation**, not
live ingestion or regulatory-status publication:

1. review the build plan against current repository paths, county inventory,
   accepted Directory Rules, and current official evidence, then remove only
   claims proven stale;
2. distinguish the dated municipal notice from controlling regulatory authority
   and define explicit temporal, supersession, and individual-applicability
   limits;
3. classify the first county, municipal, GIS/appraisal, regulatory, geology,
   museum, agriculture, and flood-routing candidates by authority, rights,
   cadence, sensitivity, correction behavior, and allowed public use before any
   activation;
4. choose one no-network synthetic county-context fixture using current semantic
   and schema authorities rather than creating parallel object homes;
5. define exact negative outcomes for individual wells and compliance,
   owner/address/property joins, fossil and scientific localities, collecting
   access, mineral/property claims, aggregate-to-private inference,
   flood/property decisions, stale status, and uncited generated language;
6. run repository-native focused and aggregate checks, then record introduced
   versus inherited failures;
7. keep live connectors, individual lookups, source-derived geometry, release,
   deployment, and publication outside that packet.

This README does not authorize that follow-up; it states the dependency-closed
boundary that a later implementation request must verify.
