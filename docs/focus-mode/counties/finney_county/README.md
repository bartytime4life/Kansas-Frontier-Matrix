# Finney County Focus Mode

> **Purpose.** Orient maintainers to the Finney County planning lane, make its
> groundwater, irrigation, agriculture, labor, immigration, public-health,
> infrastructure, drought, and ecological boundaries visible, and route future
> work through KFM evidence, policy, review, release, correction, and rollback
> controls.

> [!IMPORTANT]
> **Tracked planning artifacts are not implementation or release evidence.**
> This directory contains this README and one Finney County build plan. Their
> presence prevents accidental duplicate planning; it does not establish source
> admission, semantic correctness, validator success, runtime behavior, release,
> deployment, or publication.

> [!CAUTION]
> **Placement remains unresolved.** This same-path update repairs an existing
> README under `docs/focus-mode/counties/finney_county/`. Accepted Directory
> Rules v2 treats Focus Mode as a composition scope; proposed ADR-0027 describes
> a different plural, kebab-case control plane but remains unaccepted. No file is
> moved, renamed, copied into a parallel tree, or declared the final canonical
> county write target here.

> [!WARNING]
> **The build plan combines public context with sensitive and high-consequence
> subjects.** Private or reconstructive immigration, worker, household,
> public-health, well, farm, ranch, water-use, facility, supply-chain,
> infrastructure, archaeology, sacred-site, and rare-species detail must not
> reach an ordinary public client. Missing evidence, rights, safe resolution,
> policy, review, or release closure must produce a bounded `ABSTAIN`, `DENY`, or
> `ERROR` result rather than a fluent inference.

## 4. Proposed Finney County proof slice

The build plan proposes a public-safe county evidence cockpit centered on the
relationships among Garden City regional context, the High Plains / Ogallala
Aquifer, irrigation agriculture, the Arkansas River corridor, meatpacking and
labor history, immigration and community change, livestock economy, drought,
and dryland ecology. That is a **planning thesis**, not a verified current
product.

| Proposed element | Evidence needed before reliance | Non-effect of this README |
|---|---|---|
| County and community orientation | Registered authoritative geography source, vintage, geometry identity, rights, and released public-safe carrier | Does not declare a current boundary artifact, settlement graph, or public layer |
| Aquifer and groundwater context | Separate observed, modeled, interpreted, policy, and legal source roles; valid time; scale; limitations; review and release evidence | Does not determine a water right, well condition, allocation, compliance posture, or future supply |
| Irrigation, crop, and livestock context | Admitted aggregate sources, measure definitions, vintage, class mapping, transform receipts, and anti-reidentification review | Does not expose private wells, farms, ranches, operators, households, or facility vulnerabilities |
| Arkansas River and floodplain context | Distinct hydrologic, historical, and regulatory source roles with valid time and limitations | Does not provide parcel-specific risk, legal, engineering, insurance, or emergency advice |
| Meatpacking, labor, immigration, and public-health context | Admitted aggregate evidence, privacy and rights review, population thresholds, uncertainty, and correction path | Does not create living-person, worker, household, citizenship, immigration-status, or health profiles |
| Drought, heat, dust, and resilience context | Current source identity, observation-versus-model label, time coverage, uncertainty, and not-an-alert presentation | Does not issue an emergency alert, forecast, field-safety instruction, or operational decision |
| Sandsage and dryland ecology context | Appropriate ecology source, rights, safe spatial resolution, cultural review, and correction path | Does not disclose exact rare-species, archaeology, burial, sacred, or otherwise protected locations |
| Map and AI interpretation | Released public-safe carriers, resolvable EvidenceBundles, finite policy outcomes, governed runtime, correction and rollback support | Does not create a layer, route, model capability, or public answer |

## 5. Public safety and governed outcomes

| Request or output class | Bounded posture | Reason |
|---|---|---|
| Released, broad, time-labeled county context with resolving citations | `ANSWER` only when evidence, policy, review, and release conditions pass | Keeps the result within admitted public-safe evidence |
| Missing, stale, conflicting, overly coarse, or unresolvable evidence | `ABSTAIN` | Fluency cannot substitute for evidence, source role, or currentness |
| Groundwater observation, modeled trend, water-use report, or map layer used as a water-rights, compliance, allocation, well-condition, or legal conclusion | `ABSTAIN` or `DENY`, with the responsible authority identified when available | Prevents scientific, temporal, regulatory, and legal role collapse |
| Private or reconstructive well, farm, ranch, operator, household, worker, immigration-status, citizenship, health, facility, supply-chain, or critical-infrastructure detail | `DENY` | Prevents privacy, safety, property, labor, immigration, health, and infrastructure harm |
| Demographic, labor, or public-health aggregates used to profile a person, family, household, employer, or small group | `DENY` | Aggregate context must not become reidentification or consequential profiling |
| Crop, land-cover, groundwater, drought, or resilience model presented as direct observation or ground truth | `ABSTAIN` or `DENY`, as accepted policy requires | Preserves observation, derivation, model, uncertainty, and valid-time distinctions |
| Drought, heat, dust, floodplain, transportation, ecology, or airport context used as an official alert, route, field-safety, emergency, or operational instruction | `ABSTAIN` and route to the responsible authority | KFM is not the operational safety or emergency authority |
| Exact archaeology, burial, sacred-site, rare-species, protected-habitat, or sensitive infrastructure detail | `DENY` | Prevents cultural, ecological, property, and infrastructure harm |
| Cross-source inference of causation, contamination, liability, eligibility, public-health diagnosis, engineering fitness, or legal responsibility | `DENY` or `ABSTAIN`, as accepted policy requires | Separate contextual sources do not jointly prove the inferred claim |
| Resolver, policy, carrier, citation, or runtime failure | `ERROR` with no unsupported fallback claim | Failure must remain visible and fail closed |

Client-side hiding is not a sensitivity control. Protected detail must not be
delivered to an ordinary public client, included in public logs or analytics, or
reconstructed from tiles, filters, search, exports, caches, identifiers, or AI
responses.

### Minimum-display rule

Even publicly visible source material does not automatically belong in a KFM
public derivative. Display the minimum resolution and attribute set required for
the reviewed public purpose. Generalization, suppression, and omission require
traceable transform reasoning; a link to an official public source remains
preferable when KFM cannot prove safe derivative use.

## 6. Source-role and currentness boundary

The plan's source list is a research queue, not an admitted source registry.
Future work must assign each candidate one bounded role and preserve the
distinctions below.

| Candidate source family named by the plan | May support after admission | Must not be collapsed into |
|---|---|---|
| Finney County and Garden City official sites | Local civic identity, office role, public-history routing, and broad service context | Complete historical authority, private-person records, or permission to republish every accessible field |
| Kansas Geological Survey aquifer and water-resource materials | Groundwater and geoscience observations or interpretation within a reviewed temporal and spatial scope | Legal water right, guaranteed supply, private-well condition, compliance decision, or timeless trend |
| USGS water observations and hydrography | Defined gage, stream, hydrographic, or groundwater observations with explicit identifiers and valid time | One complete aquifer truth, local legal conclusion, current emergency state, or causation claim |
| Kansas Department of Agriculture Division of Water Resources materials | Bounded water-use, administration, or regulatory context under the source's actual authority | Automatic legal determination, title, permission, enforcement outcome, or private-water-use dossier |
| USDA NASS Cropland Data Layer and related agriculture products | Reviewed generalized or aggregate crop and land-cover context with derived status visible | Ground truth, farm/operator identity, parcel use, private well location, or precise business behavior |
| Academic meatpacking, immigration, and labor studies | Time-bounded aggregate historical or social-science interpretation with methods and limitations | Current person, worker, citizenship, household, employer, health, or vulnerability profile |
| NOAA climate and drought materials | Defined historical observation or modeled climate/drought context with currentness and uncertainty | Official local alert, precise forecast, operational instruction, or causal conclusion |
| FEMA, hydrography, and public-history sources | Their separate regulatory, physical, or historical roles after admission | One undifferentiated flood, river, property, or historical truth |

For every admitted source, record authority role, access method, rights and terms,
geographic and temporal scope, cadence, known limitations, sensitivity,
correction behavior, and the evidence references it may support. A browsed page,
source seed, or polished citation is not an `EvidenceBundle`.

## 7. Evidence and readiness boundary

A Finney County public result must remain downstream of the governed KFM path:

1. identify a source once in the source-authority surface;
2. review authority, rights, access, time, geography, sensitivity, and correction
   behavior;
3. admit candidate material to `RAW`, or hold it in `WORK / QUARANTINE` when
   requirements are unresolved;
4. derive and validate `PROCESSED` material with transform and provenance
   lineage;
5. resolve every consequential `EvidenceRef` to an `EvidenceBundle` and apply
   policy;
6. make a separate promotion and release decision with correction and rollback
   targets;
7. serve only released public-safe artifacts through governed interfaces;
8. keep map rendering and AI interpretation subordinate to that evidence and
   decision state.

## 8. Smallest safe follow-up

The build plan's smallest dependency-closed implementation candidate is a
**no-network, synthetic, fixture-backed public-safe source-to-card proof**. It
should reuse current accepted object families and validators where they exist;
new contracts, schemas, policy, or paths require their own verified placement
and compatibility review.

### Candidate fixture set

| Scenario | Expected outcome or property |
|---|---|
| County identity and broad Garden City context with resolving evidence | `ANSWER` after policy and release prerequisites pass |
| Time-labeled aquifer observation with explicit source role and limitations | `ANSWER` for reviewed context; `ABSTAIN` for private-well or legal conclusions |
| Generalized irrigation and crop context with derived status visible | `ANSWER` without farm, ranch, operator, household, parcel, or exact water-use inference |
| Aggregate meatpacking, labor, immigration, and community-history card | `ANSWER` without person-, worker-, household-, citizenship-, employer-, or health-level profiling |
| Private well, farm, worker, immigration-status, health, facility, or supply-chain detail | `DENY` |
| Water or groundwater data presented as a legal water-rights determination | `DENY` |
| Crop, groundwater, or drought model presented as ground truth or official alert | `ABSTAIN` or `DENY`, according to accepted policy |
| Exact archaeology, burial, sacred-site, rare-species, or sensitive infrastructure location | `DENY` |
| Unresolved, stale, conflicting, or revoked evidence | `ABSTAIN` |
| AI narrative without a resolving EvidenceBundle | `ABSTAIN` or `ERROR`, according to the accepted envelope contract |
| Public payload reading `RAW`, `WORK`, `QUARANTINE`, or direct model output | `ERROR` |

### Go / hold boundary

| Transition | Required evidence | If absent |
|---|---|---|
| Revise the sibling plan | Current source, rights, path, contract, and maturity review | Keep the plan proposed |
| Add synthetic fixtures | Verified object homes, stable reason semantics, no production or sensitive data | Keep documentation only |
| Add policy or validators | Accepted owning boundary, positive and negative tests, compatibility review | Do not create county-local policy authority |
| Add mock governed UI/API behavior | Fixture proof, released-carrier simulation, trust-visible negative states, accessibility checks | No runtime or UI claim |
| Prepare a release candidate | Evidence, rights, sensitivity, policy, independent review, correction, withdrawal, and rollback closure | `HOLD` |
| Publish | Separate governed promotion and publication authority | `DENY` publication by inference |

This README performs none of those transitions. It records the review boundary
so a future slice can be dependency-closed and independently reversible.

- the Finney directory, sibling plan, county index, parent Focus documentation,
  or county template changes;
- ADR-0027, ADR-0029, or accepted Directory Rules authority changes;
- a Finney source is admitted, corrected, superseded, or rejected;
- a county contract, schema, policy profile, validator, fixture, governed API
  route, renderer, or AI adapter becomes reviewable;
- groundwater or water-rights handling, agricultural privacy, labor or
  immigration privacy, public-health aggregation, facility sensitivity,
  drought/currentness, ecological geoprivacy, or public-safety posture changes;
- a promotion, release, correction, withdrawal, or rollback object is proposed.

### Validation for this documentation slice

The authoring change should verify:

- one metadata block, one H1, ordered headings, balanced comments and fences,
  consistent tables, unique anchors, and a final newline;
- every same-document fragment and repository-relative link;
- exact final-byte SHA-256 and Git blob identity;
- absence of coordinates, credentials, private endpoints, personal data, exact
  protected locations, live operational payloads, and unsupported current-state
  claims;
- generated-receipt schema and artifact-hash parity;
- exact branch comparison, changed paths, remote bytes, and draft PR state.

Repository-native full validation and hosted exact-head checks remain separate
evidence. Any unavailable or inherited failure must be classified rather than
silently waived.

### Rollback and correction

Before merge, close or abandon the draft PR and leave `main` unchanged. After an
authorized merge, revert the README and its generated authoring receipt together,
or apply a bounded forward correction against the actual merged bytes. Do not
revert the sibling plan, county index, contracts, schemas, policy, validators,
applications, or release objects unless a later change explicitly included them.

This documentation rollback would not reverse a source admission, policy
decision, runtime change, release, deployment, or publication because none is
created here.
