# Crawford County Focus Mode

> **Purpose.** Orient maintainers to the Crawford County planning lane, make its
> coal-field, mined-land, floodplain, parcel, historic-resource, wildlife,
> transportation, and public-safety boundaries visible, and route future work
> through KFM evidence, policy, review, release, correction, and rollback
> controls.

> [!IMPORTANT]
> **Tracked planning artifacts are not implementation or release evidence.**
> This directory contains this README and one Crawford County build plan. Their
> presence prevents accidental duplicate planning; it does not establish source
> admission, semantic correctness, validator success, runtime behavior, release,
> deployment, or publication.

> [!CAUTION]
> **Placement remains unresolved.** This same-path update repairs an existing
> README under `docs/focus-mode/counties/crawford_county/`. Accepted Directory
> Rules v2 treats Focus Mode as a composition scope; proposed ADR-0027 describes
> a different plural, kebab-case control plane but remains unaccepted. No file is
> moved, renamed, copied into a parallel tree, or declared the final canonical
> county write target here.

> [!WARNING]
> **The build plan combines public context with sensitive and high-consequence
> subjects.** Exact or reconstructive abandoned-mine, subsidence, archaeology,
> burial, sacred-site, rare-species, private-property, living-person, and
> critical-infrastructure detail must not reach an ordinary public client.
> Missing evidence, rights, safe resolution, policy, review, or release closure
> must produce a bounded `ABSTAIN`, `DENY`, or `ERROR` result rather than a fluent
> inference.

relationship among settlement context, coal-field history, mined-land ecology,
floodplain status, aggregate agriculture, transportation, and public historic
resources. That is a **planning thesis**, not a verified current product.

| Proposed element | Evidence needed before reliance | Non-effect of this README |
|---|---|---|
| County and municipal orientation | Registered authoritative geography source, vintage, geometry identity, rights, and released public-safe carrier | Does not declare a current boundary artifact, settlement graph, or public layer |
| Floodplain status context | Separate county, state, and federal source roles; effective/draft status; valid time; limitations; policy and release evidence | Does not provide parcel-specific risk, insurance, legal, engineering, or emergency advice |
| Coal-field and mined-land context | Appropriate KGS, KDWP, historical, ecology, and safety source roles; scale; time; rights; public-safe transform receipts | Does not expose exact abandoned-mine, subsidence, unsafe-access, or hazard geometry |
| Aggregate agriculture and land-cover context | Admitted aggregate source, measure definitions, vintage, class mapping, transform receipt, and anti-reidentification review | Does not authorize farm-, operator-, household-, or parcel-specific inference |
| Transportation context | Current, rights-cleared public transportation source and non-operational presentation rules | Does not provide routing, evacuation, incident, or infrastructure-vulnerability analysis |
| Public historic-resource context | Public-source authority, rights, cultural review, safe resolution, and correction path | Does not disclose exact archaeology, burial, sacred, private-residence, or protected-site detail |
| Map and AI interpretation | Released public-safe carriers, resolvable EvidenceBundles, finite policy outcomes, governed runtime, correction and rollback support | Does not create a layer, route, model capability, or public answer |

## 5. Public safety and governed outcomes

| Request or output class | Bounded posture | Reason |
|---|---|---|
| Released, broad, time-labeled county context with resolving citations | `ANSWER` only when evidence, policy, review, and release conditions pass | Keeps the result within admitted public-safe evidence |
| Missing, stale, conflicting, overly coarse, or unresolvable evidence | `ABSTAIN` | Fluency cannot substitute for evidence, source role, or currentness |
| Draft floodplain material presented as effective, final, regulatory, or parcel-specific truth | `ABSTAIN` or `DENY`, with the responsible official source identified when available | Prevents status collapse and unsafe property reliance |
| Exact or reconstructive abandoned-mine, subsidence, unsafe-access, archaeology, burial, sacred-site, rare-species, private-parcel, living-person, or critical-infrastructure detail | `DENY` | Prevents safety, privacy, cultural, ecological, property, and infrastructure harm |
| Parcel-map or assessor context used as title, ownership, eligibility, valuation, liability, or legal proof | `DENY` or `ABSTAIN`, as accepted policy requires | A contextual map cannot establish those decisions |
| Recreation or ecology context used as a field-safety, access, or emergency instruction | `ABSTAIN` and route to the responsible authority | KFM is not the operational safety or emergency authority |
| Cross-source inference of causation, contamination, compliance, engineering fitness, insurance status, or legal responsibility | `DENY` or `ABSTAIN`, as accepted policy requires | Separate contextual sources do not jointly prove the inferred claim |
| Resolver, policy, carrier, citation, or runtime failure | `ERROR` with no unsupported fallback claim | Failure must remain visible and fail closed |

Client-side hiding is not a sensitivity control. Protected detail must not be
delivered to an ordinary public client, included in public logs or analytics, or
reconstructed from tiles, filters, search, exports, caches, identifiers, or AI
responses.

### Minimum-display rule

Even publicly visible source material does not automatically belong in a KFM
public derivative. Display the minimum resolution and attribute set required for
the reviewed public purpose. Generalization, suppression, and omission require
traceable transform reasoning; a link to an official public source remains
preferable when KFM cannot prove safe derivative use.

## 6. Source-role and currentness boundary

The plan's source list is a research queue, not an admitted source registry.
Future work must assign each candidate one bounded role and preserve the
distinctions below.

| Candidate source family named by the plan | May support after admission | Must not be collapsed into |
|---|---|---|
| Crawford County GIS, maps, and addressing pages | Local map availability, office role, broad county context | Title truth, verified ownership, living-person dossiers, or permission to republish every parcel attribute |
| County, KDA, and FEMA floodplain surfaces | Distinct communication, draft-map, or regulatory-source roles with explicit valid time | One undifferentiated final flood truth or parcel-specific determination |
| KGS geology and coal materials | Historical and geologic context at an approved resolution | Live mine-safety judgment, exact abandoned-mine hazard, subsidence prediction, or access guidance |
| KDWP mined-land materials | Official public ecology, management, or recreation context | Geology authority, mine-safety authority, guaranteed access, or safe-field instruction |
| KDA, USDA NASS, Census, and land-cover products | Defined county aggregates or reviewed generalized derivatives | Farm/operator identification, household inference, private-property conclusion, or timeless statistics |
| KDOT and county transportation products | General transportation context at an approved vintage | Live routing, emergency movement, operational weakness, or infrastructure vulnerability |
| KHRI, SHPO, and related historic-resource surfaces | Reviewed public built-resource education and source routing | Permission to expose archaeology, burial, sacred, culturally sensitive, private-residence, or protected-site detail |

For every admitted source, record authority role, access method, rights and terms,
geographic and temporal scope, cadence, known limitations, sensitivity,
correction behavior, and the evidence references it may support. A browsed page,
source seed, or polished citation is not an `EvidenceBundle`.

## 7. Evidence and readiness boundary

A Crawford County public result must remain downstream of the governed KFM path:

1. identify a source once in the source-authority surface;
2. review authority, rights, access, time, geography, sensitivity, and correction
   behavior;
3. admit candidate material to `RAW`, or hold it in `WORK / QUARANTINE` when
   requirements are unresolved;
4. derive and validate `PROCESSED` material with transform and provenance
   lineage;
5. resolve every consequential `EvidenceRef` to an `EvidenceBundle` and apply
   policy;
6. make a separate promotion and release decision with correction and rollback
   targets;
7. serve only released public-safe artifacts through governed interfaces;
8. keep map rendering and AI interpretation subordinate to that evidence and
   decision state.

## 8. Smallest safe follow-up

The build plan's smallest dependency-closed implementation candidate is a
**no-network, synthetic, fixture-backed public-safe source-to-card proof**. It
should reuse current accepted object families and validators where they exist;
new contracts, schemas, policy, or paths require their own verified placement
and compatibility review.

### Candidate fixture set

| Scenario | Expected outcome or property |
|---|---|
| County identity and broad settlement context with resolving evidence | `ANSWER` after policy and release prerequisites pass |
| County-level agriculture profile with defined vintage and aggregate measures | `ANSWER` without farm-, operator-, household-, or parcel-level inference |
| Floodplain card with explicit draft/effective status and official-source route | `ANSWER` for status context; `ABSTAIN` for parcel determination |
| Generalized coal-field and mined-land context | `ANSWER` without exact hazard or unsafe-access detail |
| Exact abandoned-mine or subsidence-sensitive location | `DENY` |
| Parcel owner, title, valuation, eligibility, or private-person inference | `DENY` |
| Exact archaeology, burial, sacred-site, or rare-species location | `DENY` |
| Unresolved, stale, conflicting, or revoked evidence | `ABSTAIN` |
| AI narrative without a resolving EvidenceBundle | `ABSTAIN` or `ERROR`, according to the accepted envelope contract |
| Public payload reading `RAW`, `WORK`, `QUARANTINE`, or direct model output | `ERROR` |

### Go / hold boundary

| Transition | Required evidence | If absent |
|---|---|---|
| Revise the sibling plan | Current source, rights, path, contract, and maturity review | Keep the plan proposed |
| Add synthetic fixtures | Verified object homes, stable reason semantics, no production or sensitive data | Keep documentation only |
| Add policy or validators | Accepted owning boundary, positive and negative tests, compatibility review | Do not create county-local policy authority |
| Add mock governed UI/API behavior | Fixture proof, released-carrier simulation, trust-visible negative states, accessibility checks | No runtime or UI claim |
| Prepare a release candidate | Evidence, rights, sensitivity, policy, independent review, correction, withdrawal, and rollback closure | `HOLD` |
| Publish | Separate governed promotion and publication authority | `DENY` publication by inference |

This README performs none of those transitions. It records the review boundary
so a future slice can be dependency-closed and independently reversible.
