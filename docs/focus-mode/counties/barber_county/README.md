## Barber County public-safety boundary

| Theme | Default public posture until closure | Evidence or review still required |
|---|---|---|
| Treaty, Nation, sacred, burial, and cultural context | Generalize, `ABSTAIN`, or `DENY`; never infer or expose sensitive locations | Appropriate Nation-authoritative participation, cultural-resource review, approved claim scope, citation, and precision policy |
| Archaeology and historic resources | Withhold exact or inference-enabling locations | Authority, rights, sensitivity classification, geometry policy, review, correction, and withdrawal path |
| Caves, karst, fragile landforms, and ecology | Generalize or deny exact locations, access routes, and vulnerable attributes | Qualified sensitivity review, land/access posture, safe geometry, negative inference tests, and release decision |
| River, water-quality, and monitoring context | Do not turn dated or observational material into current health, legal, safety, or regulatory advice | Source-role separation, temporal fitness, current authority, disclaimers, outage/staleness behavior, and policy decision |
| Recreation, roads, projects, and conditions | Route current rules and conditions to responsible official services; otherwise abstain | Freshness, operational authority, access/safety limits, and correction behavior |
| Parcels, ownership, title, and access | `DENY` title/access conclusions and private-location inference | Governed source and rights basis, privacy and harmful-precision review, legal limits, and approved public projection |
| Agriculture and working lands | Prefer reviewed aggregates; prevent re-identification or farm-level inference | Aggregation threshold, source rights, temporal basis, privacy review, and validation |

These are fail-closed planning constraints. They are not new policy decisions and do not replace specialist or authority-holder review.

## Trust path and finite outcomes

A public Barber County claim would need to follow the established KFM trust direction:

```text
source candidate
  -> RAW capture
  -> WORK / QUARANTINE review
  -> PROCESSED role-aware object
  -> EvidenceRef -> EvidenceBundle
  -> CATALOG / TRIPLETS projection
  -> policy + validation + review + release decision
  -> PUBLISHED public-safe artifact
  -> Governed API
  -> Explorer presentation
```

The map, UI, catalog, index, AI response, and this README are downstream or interpretive surfaces; none is sovereign truth.

| Outcome | Meaning |
|---|---|
| `ANSWER` | Evidence, policy, citation, time, precision, release, and consumer requirements all permit the bounded claim. |
| `ABSTAIN` | Evidence, freshness, authority, rights, geometry, or release support is insufficient. |
| `DENY` | The requested disclosure or use conflicts with sensitivity, privacy, safety, rights, access, or release controls. |
| `ERROR` | Required object shape, resolver, validator, or governed service failed; do not degrade into an unsupported answer. |

## Maintenance, correction, and rollback

When this directory changes:

1. Re-pin `main`, the target blob, sibling plan blob, and governing evidence.
2. Reconcile open PR and branch overlap before editing shared bytes.
3. Keep this README synchronized only with confirmed directory and maturity state.
4. Preserve plan proposals as proposals; correct overclaims rather than promoting them through prose.
5. Update direct links and the county index only when their inventory facts change.
6. Emit a receipt bound to the final authored bytes and leave human review pending.
7. Re-run focused checks and inspect exact-head hosted results without weakening failures.

**Before merge**, rollback is closing or abandoning the draft PR and leaving `main` unchanged; remote branch deletion is separate authority. **After merge**, use a transparent revert or bounded forward-fix PR for this README and its receipt. Never force-push shared history, create a second writable county lane, or treat Git rollback as sufficient correction for separately released public artifacts.
