# Jackson County Focus Mode

> **Purpose.** Orient maintainers to the Jackson County planning lane, make its
> sovereignty, cultural-authority, ecological-precision, agriculture, privacy,
> operational-currentness, and evidence boundaries visible, and route future
> work through KFM source, evidence, policy, review, release, correction, and
> rollback controls.

> [!IMPORTANT]
> **Tracked planning artifacts are not implementation, consent, approval, or
> release evidence.** This directory contains this README and one Jackson County
> build plan. Their presence prevents accidental duplicate planning; it does not
> establish source admission, Nation authorization, semantic correctness,
> validator success, runtime behavior, release, deployment, or publication.

> [!CAUTION]
> **Placement remains a compatibility question.** This same-path update repairs
> an existing README under `docs/focus-mode/counties/jackson_county/`. Accepted
> Directory Rules v2 governs placement; proposed ADR-0027 describes a plural,
> kebab-case control plane but remains unaccepted. No file is moved, renamed,
> copied into a parallel tree, or declared canonical here.

> [!WARNING]
> **Sovereign authority comes before county storytelling.** The linked build
> plan identifies Prairie Band Potawatomi Nation-authored material as the
> required starting point for any substantive Nation-related representation.
> County, state, federal, historical, tourism, map, or generated sources cannot
> replace Nation-authored evidence or appropriate review for identity, culture,
> language, governance, consent, endorsement, or sensitive-place decisions.

> [!WARNING]
> **Sensitive and unsafe inference must fail closed.** Exact or reconstructive
> sacred, burial, archaeological, culturally restricted, ecological-occurrence,
> living-person, ownership, parcel, title, tax, public-safety, access, or
> infrastructure-vulnerability detail must not reach an ordinary public client.
> Missing authority, evidence, rights, safe geometry, freshness, policy, or
> review closure requires `ABSTAIN`, `DENY`, or `ERROR`, not a fluent inference.

## 4. Proposed Jackson County proof slice

The build plan proposes a narrow public-safe learning slice organized around
four related but non-interchangeable concerns:

1. **Jackson County and Holton orientation** — public routing and geographic
   context without parcel, ownership, genealogy, or living-person inference.
2. **Banner Creek Reservoir public context** — a reservoir-scale place and
   recreation card without current operational guidance or ecological location
   intelligence.
3. **2022 county agriculture aggregate** — the plan records 783 farms, 263,210
   acres, and $91 million in sales from a KDA/USDA source checked on 2026-05-22;
   those values remain plan evidence, not a current admitted KFM dataset.
4. **Visible sovereignty-review boundary** — Nation-related representation is
   withheld until Nation-authored evidence, rights, sensitivity treatment, and
   appropriate review are established.

### Proposed first-slice surfaces

| Proposed surface | Intended value | Required boundary |
|---|---|---|
| Jackson County orientation frame | Locate the county and safe named-place context | No owner, parcel, tax, title, residence, private-access, tribal-territory, or cultural-place inference |
| Banner Creek public-context card | Present bounded county-authored place and recreation context | Reservoir scale only; no current rules, safety, water quality, hunting condition, or sensitive ecology |
| Agriculture aggregate card | Communicate the plan's time-bounded 2022 county totals | Aggregate only; no farm, operator, facility, worker, household, parcel, or vulnerability inference |
| County history source-router card | Show a future intake route without manufacturing a narrative | Source lead only; not Nation authority, genealogy, cultural meaning, or released synthesis |
| Sovereignty-review notice | Explain intentional withholding and safe next steps | No substantive Nation-related claim, implied hidden geometry, consent, endorsement, or cultural detail |
| Evidence Drawer and boundary panels | Expose source role, time basis, limitations, evidence, review, and reason codes | Unresolved evidence, policy, rights, or release state cannot be polished into an answer |

These are **PROPOSED planning surfaces**. No card, layer, payload, source
descriptor, evidence bundle, policy decision, route, or released artifact is
confirmed by this README.

### Deferred planning surfaces

- hydrology, floodplain, water-quality, or current reservoir-condition context;
- transportation, road, or current routing context;
- geology and other cross-domain extensions;
- structured historical, archaeological, cultural, or language content;
- exact species observations, nests, roosts, habitats, or hunting locations;
- live operational notices or current-condition integrations.

Each deferred item needs source identity, rights, version/effective state,
geometry fitness, sensitivity review, public-safe transformation, evidence
closure, policy, and release support before display.

### Excluded or denied by default

- unreviewed Nation-related land, governance, history, culture, language,
  treaty, route, or place representation;
- sacred, burial, archaeological, or culturally sensitive locations or
  reconstructive hints;
- exact ecological observations, nests, roosts, sensitive-species occurrences,
  habitat-management detail, or hunting hot spots;
- owner, family, genealogy, tax, title, parcel, residence, living-person, farm,
  operator, or private-access inference;
- current boating, hunting, safety, regulation, flood, road, weather,
  emergency, or public-safety advice;
- critical-infrastructure, access-control, or vulnerability detail;
- direct public access to `RAW`, `WORK`, `QUARANTINE`, restricted source
  material, unpublished candidates, canonical stores, or model output.

## 5. Sovereign authority and source-role boundary

### Authority before synthesis

The build plan identifies the Prairie Band Potawatomi Nation official source
family as the required starting point for any substantive Nation-related
representation. It also records that content retrieval was blocked in the
planning run. That is a candidate authority route and a reason to withhold
content—not proof of permission, consent, endorsement, a review relationship,
or an authorized public scope.

Before any substantive Nation-related card can be released, the implementation
must establish at minimum:

- the correct Nation-authored source identity and authority role;
- the exact public statements or assets proposed for citation or display;
- rights, attribution, excerpting, caching, translation, and derivative-use
  obligations;
- the appropriate review relationship and accountable reviewer;
- protected, withheld, generalized, link-only, or prohibited categories;
- correction, withdrawal, supersession, and contact behavior.

### Source-role anti-collapse

| Candidate source role named by the plan | May support after admission and review | Must not become |
|---|---|---|
| Prairie Band Potawatomi Nation official material — Nation-authority candidate | Attributed Nation-authored public context within an explicitly reviewed scope | KFM-originated cultural authority, territorial assertion, consent, endorsement, sensitive-place disclosure, or unrestricted derivative product |
| Jackson County official site — administrative candidate | County identity, official service routing, and public entry points | Nation authority, title truth, current safety verdict, or permission to expose private records |
| Banner Creek Reservoir county page — public-place candidate | Bounded reservoir-scale context and official redirect | Live regulation, safety, water-quality, ecological-occurrence, or hunting authority |
| KDA/USDA 2022 county profile — aggregate candidate | Time-bounded county agriculture totals with units and limitations | Farm, operator, owner, parcel, facility, worker, household, or current-condition truth |
| Jackson County history page — source-router candidate | A reviewed lead for future evidence intake | Nation-authored history, genealogy, cultural authority, or released KFM narrative |
| Generated KFM narrative — downstream interpretation | A bounded summary of resolved, released, policy-safe evidence | Evidence, authority, consent, review, policy, or release state |

### Cultural and ecological precision

Public availability does not equal public-display fitness. A historical,
cultural, ecological, recreation, or map source may be readable yet contain
relationships, descriptions, or location details that should not be reproduced
in a map, fixture, screenshot, search index, AI answer, log, or export.

The public product should communicate only the safe category and reason for
withholding. It must not reveal suppressed detail through coordinates, camera
centering, labels, identifiers, prose hints, metadata, tiles, accessibility
text, caches, exports, or repeated-query reconstruction.

### Generated-language boundary

AI may summarize only an already resolved, policy-allowed, review-supported,
released public-safe evidence bundle. It cannot:

- infer a Nation's identity, meaning, consent, endorsement, territory, or
  current position;
- decide cultural, sacred, burial, archaeological, or ecological sensitivity;
- convert a county history lead into Nation authority or genealogical truth;
- convert a county aggregate into a farm, owner, parcel, facility, worker, or
  household claim;
- decide source rights, policy, review, promotion, or release;
- use hidden reasoning or model confidence as evidence.

## 6. Public safety and governed outcomes

### Finite outcomes

| Outcome | Jackson County use | Required visible state |
|---|---|---|
| `ANSWER` | A bounded public-safe orientation, Banner Creek context, agriculture aggregate, source-router, or review-boundary response is supported by released evidence and policy | Evidence references, source roles, time basis, limitations, review/release state, and correction route |
| `ABSTAIN` | Evidence, authority, effective state, freshness, geometry, rights, or scope is insufficient; current reservoir, hunting, flood, road, or safety guidance is requested | Stable reason code, evidence gap, official redirect where safe, and no answer-like fallback |
| `DENY` | The request seeks unreviewed Nation-related representation, cultural or ecological precision, ownership/genealogy, living-person detail, restricted content, or trust-membrane bypass | Stable reason code and safe alternative without leaking protected detail |
| `ERROR` | A required schema, evidence resolver, policy evaluator, citation check, release record, or governed service failed | Stable error code; no permissive answer or raw-data fallback |

### Candidate reason-code families from the build plan

| Boundary | Candidate reason codes | Expected posture |
|---|---|---|
| Sovereign authority and review | `sovereignty.authority_review_required` | `ABSTAIN` or `DENY` unsupported Nation-related representation |
| Cultural sensitivity | `cultural.sensitive_location` | `DENY` precise or reconstructive sensitive-place detail |
| Ecology geoprivacy | `ecology.exact_sensitive_geometry` | `DENY` exact observation, nest, roost, or discovery guidance |
| People and land | `privacy.person_land_detail`, `privacy.aggregate_reidentification_risk` | `DENY` private detail or aggregate-to-person/parcel inference |
| Operational currentness | `operational.current_authority_required` | `ABSTAIN` and route to current official authority |
| Evidence and citations | `evidence.unresolved_ref`, `citation.missing_support` | `ABSTAIN` or `ERROR` |
| Rights | `rights.unknown_for_redistribution` | `DENY` derivative or export until resolved |
| Trust membrane and release | `release.not_published`, `trust_membrane.bypass` | `DENY` candidate/internal/model access |
| Non-leaking refusal | `sensitivity.existence_leak` | Rewrite or deny without confirming protected detail |

These codes are plan-derived candidates. They are not confirmed as the
repository's canonical reason-code registry and must be reconciled before
machine use.

### Required negative paths

A credible Jackson proof must include deterministic, synthetic, no-network
negative fixtures showing at least:

1. unreviewed Nation-related geometry fails closed;
2. generated Nation-related history cannot substitute for admitted evidence;
3. sacred, burial, archaeological, or cultural-place precision is denied;
4. exact sensitive-species, nest, roost, or discovery guidance is denied;
5. a reservoir context source cannot become current regulation or safety advice;
6. agriculture aggregates cannot become owner, operator, parcel, facility,
   worker, or household claims;
7. owner, family, genealogy, tax, title, and living-person material is excluded;
8. unresolved evidence cannot produce `ANSWER`;
9. unknown redistribution rights block public derivative or export;
10. public clients cannot read candidate or non-published lifecycle lanes;
11. refusal wording cannot leak protected content existence.

### Map, API, and AI boundary

A public map or Focus answer must consume a governed, public-safe projection.
It must never use the county planning directory as a data source and must never
treat a selected feature, map extent, badge, schema pass, model response, or
Markdown claim as evidence truth.

The build plan's proposed Evidence Drawer and sovereignty-review panel are
useful trust surfaces only when they project real evidence, policy, review, and
release objects. UI polish without those dependencies must remain explicitly
demonstrative.

6. retain the strongest sovereignty, cultural, ecology, agriculture, privacy,
   operational, reason-code, and no-network negative-fixture boundaries without
   claiming implementation;
7. define a bounded acceptance packet for later review rather than a live or
   public product.

### Explicit non-goals for that follow-up

- no external source activation, retrieval, or ingestion;
- no assertion of Nation consent, approval, endorsement, territory, or reviewed
  public scope;
- no cultural, sacred, burial, archaeological, ecological-occurrence, parcel,
  ownership, title, genealogy, farm, operator, or living-person data;
- no live reservoir, boating, hunting, flood, road, weather, emergency, or
  safety integration;
- no contract, schema, policy, validator, fixture, runtime, map, or API change;
- no path migration or ADR acceptance;
- no promotion, release, deployment, or publication.

### Later implementation order

Only after the build-plan reconciliation should maintainers consider a
separate, fixture-first implementation slice:

1. inspect and settle shared contract/schema ownership;
2. define a non-sensitive Jackson profile and explicit source-role vocabulary;
3. add synthetic valid and invalid fixtures;
4. implement fail-closed sovereignty, cultural, ecology, privacy, currentness,
   rights, and evidence-resolution checks;
5. prove finite outcomes through a mock governed interface;
6. perform a release/correction/rollback dry run;
7. seek the accountable reviews needed for any public-safe release.
