# Clay County Focus Mode Documentation Boundary

> **Purpose.** This directory is the current human planning lane for a proposed Clay County Focus Mode centered on Milford Lake, the Republican River, reservoir and recreation currentness, and county civic-routing boundaries. It links the sibling build plan to KFM evidence, sensitivity, validation, release, correction, and rollback requirements without claiming that the planned product exists.

> [!IMPORTANT]
> **Documentation is not a release.** Neither this README nor the sibling plan admits a source, resolves an `EvidenceRef`, creates a governed payload, approves a layer, deploys a route, or publishes a county experience.

> [!CAUTION]
> **Path convergence remains on HOLD.** The tracked singular, snake_case lane is current repository fact. ADR-0027 describes a proposed plural, kebab-case county control plane; it is not accepted authority for a move, rename, duplicate tree, or seven-file migration.

> [!WARNING]
> **Clay County planning includes high-consequence currentness and disclosure boundaries.** Reservoir levels and releases, launch ramps, boating and swimming safety, harmful algal blooms, park or road status, hunting and fishing rules, parcel/title/access, floodplain and insurance meaning, wildlife precision, infrastructure detail, and active emergencies must fail closed until the appropriate evidence, authority, temporal, policy, and review controls are verified.

## Source-role and temporal anti-collapse

The sibling plan names several source families and generated surfaces. Their roles must remain distinct.

| Source or carrier class | Potential bounded role | Must not be treated as |
|---|---|---|
| Federal reservoir/project material named by the plan | Reservoir identity, stable project context, and official-current routing after admission | Automatic live lake, ramp, flood, boating, infrastructure, or emergency truth |
| State park, wildlife, and recreation material named by the plan | Park and generalized wildlife context plus current-authority routing | Personal permission, health verdict, current closure guarantee, or exact sensitive occurrence |
| Clay County civic-routing surfaces named by the plan | Direct users to county services and explain source roles | Title, ownership, access, valuation, zoning, flood-insurance, or active emergency determination |
| Environmental-health or harmful-algal-bloom authority | Current health or advisory status only when independently admitted and temporally fit | A status inferred from a park page, old snapshot, model, or generated summary |
| Maps, cards, tiles, dashboards, and indexes | Downstream public-safe carriers after release | Canonical evidence, policy permission, or publication authority |
| Generated or AI language | Bounded explanation over resolved evidence | Source evidence, current operational status, legal advice, or release approval |

Temporal distinctions also remain explicit:

| Time field | Clay County purpose |
|---|---|
| `source_time` | When the responsible source says the condition or rule applies |
| `retrieved_at` | When KFM obtained the material |
| `valid_from` / `valid_to` | The supported time window, when supplied |
| `expires_at` | When a currentness-dependent claim must stop being used |
| `released_at` | When a governed KFM artifact entered an authorized release |
| `corrected_at` / `withdrawn_at` | When public interpretation changed or was removed |

A missing or ambiguous time basis produces `ABSTAIN`, `DENY`, `HOLD`, or `ERROR`; it does not produce a plausible present-tense answer.

## Trust path and finite outcomes

A public Clay County claim would need to follow the established KFM trust direction:

```text
source candidate
  -> RAW capture
  -> WORK / QUARANTINE review
  -> PROCESSED role-aware object
  -> EvidenceRef -> EvidenceBundle
  -> CATALOG / TRIPLET projection
  -> policy + validation + review + release decision
  -> PUBLISHED public-safe artifact
  -> Governed API
  -> Explorer presentation
```

The map, UI, catalog, index, AI response, sibling plan, and this README are downstream or interpretive surfaces; none is sovereign truth.

| Outcome | Meaning | Clay example |
|---|---|---|
| `ANSWER` | Evidence, source role, citation, time, precision, policy, review, and release requirements permit a bounded claim | Explain a released, stable reservoir-context statement with citations and limitations |
| `ABSTAIN` | Evidence, freshness, authority, geometry, rights, or release support is insufficient | Decline to say whether a ramp, road, park, water body, or emergency condition is safe or current |
| `DENY` | Disclosure or use conflicts with privacy, rights, sensitivity, access, safety, legal, infrastructure, or release controls | Refuse parcel-owner/access conclusions, exact sensitive wildlife locations, or vulnerability detail |
| `ERROR` | A required object shape, resolver, validator, policy service, or governed interface failed | Return a bounded failure without leaking internal or restricted material |

An official redirect is a routing aid, not an `ANSWER` from KFM.
