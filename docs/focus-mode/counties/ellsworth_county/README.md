# Ellsworth County Focus Mode Documentation Boundary

> **Purpose.** This directory is the current human planning lane for a proposed Ellsworth County Focus Mode. It connects the sibling build plan to KFM evidence, historical and environmental context, sensitive-location, public-interface, validation, release, correction, and rollback boundaries without claiming that the planned product exists.

> [!IMPORTANT]
> **Documentation is not a release.** Neither this README nor the sibling plan admits a source, resolves an `EvidenceRef`, creates a governed payload, approves public geometry, deploys a route, or publishes a county experience.

> [!CAUTION]
> **Path convergence remains on HOLD.** The tracked singular, snake_case lane is current repository fact. ADR-0027 describes a proposed plural, kebab-case control plane; it is not accepted authority for a move, rename, or parallel tree.

> [!WARNING]
> **Ellsworth planning combines historical, hydrologic, environmental, settlement, transport, and map context with potentially sensitive detail.** Exact or reconstructive archaeological, burial, sacred, ecological, living-person, private-property, emergency, or infrastructure detail must fail closed until evidence, rights, time, geometry, policy, and accountable review are complete.

The sibling plan names **Ellsworth County Focus Mode Control Plane** as its next milestone and proposes a fixture-first path before richer UI or live source intake. A bounded proof slice would separate orientation, historical claims, hydrologic and environmental context, time, evidence, and public-safety decisions:

| Candidate element | Proposed role | Required boundary |
|---|---|---|
| Ellsworth County orientation | Broad administrative and map frame | Registered geography, vintage, rights, geometry identity, and no property or legal inference |
| Town and settlement context | Explain place structure across time | Temporal scope, source roles, citations, uncertainty, correction, and no living-person inference |
| Fort Harker and Kanopolis context | Historical anchor and candidate atlas card | Claim-level evidence, institutional or primary/context-source roles, limitations, and correction path |
| Smoky Hill River context | Hydrologic orientation | Distinguish descriptive, observed, regulatory, forecast, emergency, and derived roles |

## Ellsworth County public-safety boundary

| Request or theme | Default posture until closure | Reason |
|---|---|---|
| Released, broad, time-labeled county context with resolving citations | `ANSWER` only after evidence, policy, review, and release pass | Keeps claims bounded to admitted public-safe evidence. |
| Missing, stale, conflicting, overly coarse, or unresolvable evidence | `ABSTAIN` | Fluency cannot substitute for evidence, source role, or currentness. |
| Exact archaeological, burial, sacred, or protected cultural location | `DENY` | Cultural sensitivity and site protection require fail-closed handling. |
| Exact ecological occurrence or other harmful-precision detail | `DENY` or reviewed generalization | Prevents reconstruction through map, search, export, cache, or AI surfaces. |
| Living-person genealogy, DNA, household, owner, title, private-access, or property-specific inference | `DENY` or `ABSTAIN` as accepted policy requires | Public records do not automatically authorize aggregation or inference. |
| Current flood, emergency, evacuation, incident, road, bridge, closure, detour, or travel instruction | `ABSTAIN` and route to the responsible live authority | Historical or contextual layers are not operational authority. |
| Parcel-level hydrology, soil, land-cover, engineering, insurance, eligibility, liability, or legal conclusion | `DENY` or `ABSTAIN` | County-scale context does not prove a site-specific decision. |
| Infrastructure vulnerability, private address, response, utility, or operational detail | `DENY` | Public context does not authorize harmful operational inference. |
| Claim with an unresolved `EvidenceRef` | `ERROR` | Missing resolution must remain visible; no unsupported fallback. |
| Public request reaching `RAW`, `WORK`, `QUARANTINE`, restricted, or direct-model content | `DENY` | Public clients use governed APIs or released public-safe artifacts only. |

These are documentation-level boundaries, not active policy. They require agreement in the canonical policy surface, evaluator, fixtures, review, runtime binding, and released carrier before any public behavior can be claimed.

## Source-role anti-collapse

A future Ellsworth slice must keep source roles explicit rather than combining every official or public page into one undifferentiated authority.

| Candidate source family implied by the plan | Permitted planning role | Must not be treated as |
|---|---|---|
| County or other administrative geography source | County frame, place identifiers, and vintage-specific boundary context | Title, ownership, access, emergency, historical, environmental, or release authority |
| Historical or institutional records | Evidence for bounded Fort Harker, Kanopolis, settlement, route, railroad, or event claims | Universal authority for every historical interpretation or modern condition |
| Hydrology and watershed sources | Role-specific river, drainage, observation, regulatory, forecast, or historical context | Interchangeable evidence, current emergency instruction, property determination, or causal proof |
| Soil or land-cover sources | Scale-appropriate observed or derived environmental context | Parcel engineering, yield, value, insurance, legal, or land-use permission conclusion |
| Transportation records | Dated project, route, or network context | Current road condition, access permission, closure, detour, bridge safety, or emergency-travel authority |
| Cultural, archaeological, ecological, or sensitive-location authority | Review and safe-scale decisions within its remit | Detail that administrative sources, generated text, or ordinary map layers may disclose by substitution |
| Generated narrative, cards, maps, and AI output | Downstream interpretation over released evidence | Evidence, policy decision, review approval, or publication authority |

Public availability, official branding, coordinates, or map detail does not by itself authorize KFM to cache, transform, tile, spatially amplify, combine, or release source material.

## Trust path and finite outcomes

A public Ellsworth County claim would need to follow the established KFM trust direction:

```text
source candidate
  -> RAW capture
  -> WORK / QUARANTINE review
  -> PROCESSED role-aware object
  -> EvidenceRef -> EvidenceBundle
  -> CATALOG / TRIPLETS projection
  -> policy + validation + review + release decision
  -> PUBLISHED public-safe artifact
  -> governed API
  -> Explorer presentation
```

The map, UI, county index, catalog, AI response, and this README are downstream or interpretive surfaces; none is sovereign truth.

| Outcome | Meaning |
|---|---|
| `ANSWER` | Evidence, policy, citation, time, precision, release, and consumer requirements all permit the bounded claim. |
| `ABSTAIN` | Evidence, freshness, authority, rights, geometry, cultural standing, currentness, or release support is insufficient. |
| `DENY` | The request conflicts with sensitivity, privacy, property, safety, rights, trust-membrane, or release controls. |
| `ERROR` | Required object shape, resolver, validator, policy evaluator, or governed service failed; do not degrade into an unsupported answer. |

`HOLD` remains a governance or workflow state rather than a public answer.

## Smallest safe follow-up

The next dependency-closed implementation should remain **no-network and fixture-first**:

1. reconcile the plan's proposed paths and object names with current accepted homes;
2. define one bounded public-safe profile for county orientation, historical claims, hydrologic role separation, time, uncertainty, property non-inference, and sensitive-location precision;
3. create deterministic valid, abstained, denied, and error fixtures without real sensitive geometry or living-person data;
4. validate source-role separation, minimum-necessary display, EvidenceRef resolution, and finite outcomes;
5. produce a mock governed response and Evidence Drawer specification from fixtures only;
6. rehearse correction and removal of a stale, unsupported, or over-precise candidate;
7. keep live source activation, production ingest, public routes, map layers, release, deployment, and publication out of scope.

Stop when the work would require unverified rights, current conditions, cultural authority, private-property adjudication, precise sensitive geometry, living-person data, site-specific conclusions, emergency data, or a parallel authority path.

## Maintenance, correction, and rollback

When this directory changes:

1. Re-pin `main`, the target blob, sibling plan blob, county index, and governing evidence.
2. Reconcile open pull requests and task-branch overlap before editing shared bytes.
3. Keep this README synchronized only with confirmed directory and maturity state.
4. Preserve plan proposals as proposals; correct stale, over-precise, or unsupported claims rather than promoting them through prose.

6. Emit a receipt bound to the final authored bytes and leave human review pending.

Never force-push shared history, create a second writable county lane, or treat Git rollback as sufficient correction for separately released public artifacts.
