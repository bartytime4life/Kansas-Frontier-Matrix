## Clark County public-safety boundary

| Request or theme | Default posture until closure | Candidate reason code |
|---|---|---|
| Predict collapse, rank danger, or score a site | `DENY` | `GEOHAZARD_PREDICTION_OUT_OF_SCOPE` |
| Show fine active-depression or geohazard geometry | `DENY`, or use an approved generalized derivative only | `FINE_GEOHAZARD_GEOMETRY_WITHHELD` |
| Give current visitor, road, route, trail, parking, or facility safety advice | `DENY`; route to an appropriate current official source outside KFM’s authority | `LIVE_VISITOR_SAFETY_ADVICE_OUT_OF_SCOPE` |
| Infer access, ownership, title, or permission from a map or public page | `DENY` | `PRIVATE_ACCESS_OR_PROPERTY_INFERENCE` |
| Locate bison or optimize a wildlife encounter | `DENY` | `LIVE_WILDLIFE_ENCOUNTER_GUIDANCE_OUT_OF_SCOPE` |
| Turn recreation context into current facility or regulatory guidance | `DENY` or `ABSTAIN` | `LIVE_RECREATION_OR_FACILITY_GUIDANCE_OUT_OF_SCOPE` |
| Decide an individual water right, well condition, jurisdiction, property risk, permit, insurance, or legal question | `DENY` | `INDIVIDUAL_WATER_OR_PROPERTY_CONCLUSION_OUT_OF_SCOPE` |
| Present a Clark water jurisdiction that has not been established by an admitted authoritative source | `ABSTAIN` | `WATER_JURISDICTION_UNVERIFIED` |
| Infer an individual or parcel fact from county aggregates | `DENY` | `AGGREGATE_TO_INDIVIDUAL_INFERENCE` |
| Display more precision than the bounded public claim requires | `ABSTAIN` and withhold excess detail | `MINIMUM_NECESSARY_DISPLAY_NOT_ESTABLISHED` |

These are proposed documentation-level reason codes inherited from the sibling plan. They do not become active policy until the canonical policy surface, evaluator, fixtures, review, and runtime binding are verified.

## Source-role anti-collapse

A future Clark slice must keep source roles explicit rather than combining every official page into one undifferentiated authority.

| Source family from the plan | Permitted planning role | Must not be treated as |
|---|---|---|
| Clark County public administration | Administrative orientation and routing | Scientific geohazard authority, property/title adjudicator, or release approval |
| Kansas Department of Wildlife and Parks | Public-land management, broad preserve/recreation context, and current official routing when verified | Geologic prediction authority, private-access permission, or perpetual current-state proof |
| Kansas Geological Survey / GeoKansas | Scientific or geologic interpretation and historical explanatory context | Current visitor-safety service, property authority, or operational warning system |
| Kansas Department of Agriculture statistics | County-scale statistical aggregate | Farm-, person-, parcel-, title-, or compliance-level evidence |
| Division of Water Resources maps/models | Candidate water-administrative or model context with explicit role | Clark-specific jurisdiction conclusion, water-right adjudication, well condition, or property/legal advice |
| Generated narrative, cards, maps, and AI output | Downstream interpretation over released evidence | Source evidence, policy decision, review approval, or publication authority |

A source’s public availability, official branding, coordinates, or map detail does not by itself authorize KFM to cache, transform, tile, spatially amplify, combine, or release it.

## Trust path and finite outcomes

A public Clark County claim would need to follow the established KFM trust direction:

```text
source candidate
  -> RAW capture
  -> WORK / QUARANTINE review
  -> PROCESSED role-aware object
  -> EvidenceRef -> EvidenceBundle
  -> CATALOG / TRIPLETS projection
  -> policy + validation + review + release decision
  -> PUBLISHED public-safe artifact
  -> governed API
  -> Explorer presentation
```

The map, UI, county index, catalog, AI response, and this README are downstream or interpretive surfaces; none is sovereign truth.

| Outcome | Meaning |
|---|---|
| `ANSWER` | Evidence, policy, citation, time, precision, release, and consumer requirements all permit the bounded claim. |
| `ABSTAIN` | Evidence, freshness, authority, rights, geometry, jurisdiction, or release support is insufficient. |
| `DENY` | The requested disclosure or use conflicts with geohazard, property/access, ecology, water, rights, sensitivity, safety, or release controls. |
| `ERROR` | Required object shape, resolver, validator, policy evaluator, or governed service failed; do not degrade into an unsupported answer. |

`HOLD` remains a governance/workflow state rather than a public answer. The plan also uses `DEFER` and `EXCLUDE` for candidate-scope decisions; they do not replace the runtime finite outcome set.
