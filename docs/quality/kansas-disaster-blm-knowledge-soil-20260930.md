This record covers the isolated implementation branches based on repository main `fe47624f32d7f355f69309048f6624c4d64bdb98` and the standalone owner-private Site candidate descended from source `75d749ed5711ab20e3edabeb1c6ba135417ec1c0` (deployed Site v131 at inspection). ## Implemented boundaries

- **Disasters:** the Site groups existing weather, fire, earthquake, streamflow, and forecast context in a disaster workspace. OpenFEMA Kansas declarations are drawn against 2020 Census county *locator* geometry, explicitly not event footprints. NFHL, Storm Events, drought, and water quality remain named holds rather than fabricated layers. Each connected source retains its own visibility, opacity, time, and status controls.
- **BLM:** the Site adds separate Kansas-filtered township, section, and intersected-division reference rasters with scale-dependent visibility. The connector captures complete paginated source GeoJSON and counts before/after; sections use the `PLSSID` Kansas prefix because their service layer lacks `STATEABBR`. These are survey-reference shapes, not parcels, title, patent footprints, or access rights. GLO remains an official on-demand link; no GLO record package is released. PAD-US attribution is separate.
- **Knowledge:** additive D1 tables model reviewed releases, the active pointer, public projections, and correction history. The versioned read API serves only the active approved, public-safe records whose values match a SHA-256-verified immutable R2 package. Search and record pages distinguish documented, conflicting, and narrative claims. The migration creates no records or active release. An exact-name GNIS source capture is now possible under the existing USGS connector family; broad GNIS, GLO, and Library of Congress intake and steward decisions remain outstanding. A composite release/record key allows corrections to retain prior released versions.
- **Soil:** the existing approximately 9 km NASA view remains separate. The Crop-CASMA candidate uses an exact advertised 2026-09-28 WCS coverage and original numeric EPSG:5070 1,000 m GeoTIFF. Nearest-neighbor CPU reprojection preserves cell values and no-data transparency. The Site's 1 km control stays held until an independently reviewed package is activated; the serving adapter verifies package and tile hashes. It shows one exact day, not a fabricated multi-day loop.
- **Dependency security:** the Site and repository mirror now pin Next.js and eslint-config-next 16.3.8 and reconcile the existing fast-uri/Undici overrides. A full npm lockfile audit reports zero findings in this local candidate. The reported critical advisory affected the Node.js `next/og` implementation; no `next/og` use was found in the inspected Site source, but patching removes the affected package version. The pinned Codex Security diff review of the earlier application patch reported no findings; it predates the final SQL key and dependency-only edits, which were checked separately.

## Unclosed gates and rollback

The current implementation requires source admission, rights/sensitivity/policy review, independent review, immutable R2 staging, approved D1 metadata, active-pointer change, browser acceptance, and rollback rehearsal before any candidate can be called released. Applying migrations alone has no public effect. Reverting the code or leaving active pointers absent restores the prior Site behavior; an activated package must be rolled back by changing the pointer to its recorded previous approved package, not by editing source bytes. A package withdrawal must make its read path abstain.
